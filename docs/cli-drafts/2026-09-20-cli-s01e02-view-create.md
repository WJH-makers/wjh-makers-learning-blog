## 二、漫画 · 被困在 less 里的人

> **〔1〕** 阿零试着敲 `cat config.yml`,整份配置哗地印在屏幕上。
> 阿零:「就这?!`cat` = 打开文件,学会了!」特米(预感不妙):「……你先别急着总结。」

> **〔2〕** 阿零转头 `cat logs/app.log`,几千行日志瀑布一样冲过屏幕,提示符被冲得没影。
> 阿零:「停!停下!它疯了!」

> **〔3〕** 特米:「`cat` 是**一次性全倒出来**,倒完就完,它没疯。大文件,`less`。」
> 阿零:「less?更少?」特米:「**一页一页给你看**的阅读器。」

> **〔4〕** 阿零敲 `less logs/app.log`,屏幕变成满屏日志。他看完想退出——按 Esc,没反应;按 Ctrl+C,没反应;敲 `exit`,屏幕只是往下滚。
> 阿零(冷汗):「我出不去了!!这是个房间没有门!!」

> **〔5〕** 特米(飘过来,只吐出一个字母):「**q**。」
> 阿零按下 q,瞬间回到提示符。阿零:「……就这?」特米:「门一直在,你不认识而已。`man` 一下,下下话教你查。」

> **〔6〕** 特米:「只想瞄一眼头尾,还有更快的刀:`head` 看头,`tail` 看尾。四把刀,看菜下刀。」

## 三、本话目标

- 掌握四把阅读刀:`cat`(全倒)、`less`(翻页)、`head`(看头)、`tail`(看尾),知道各自何时出鞘;
- 在 `less` 里活着出来:Space 下一页、`/` 搜索、`q` 退出;
- 用 `mkdir` / `touch` 创造目录与空文件;
- 首见 `echo` 与重定向 `>`:把文字写进文件;
- 踩一次 `>` 的静默覆盖坑,并认识救星 `>>`。

---

## 四、原理图:读的四把刀,写的一条管

```text
读文件 —— 按大小选刀:
cat  file     全部倒出   ← 小文件(几十行内)
less file     翻页阅读   ← 大文件(日志、长配置)
head -n 5     只看前 5 行 ← 探个头
tail -n 5     只看后 5 行 ← 日志最新几条(排障最常用)

造东西:
mkdir 名字     造目录      touch 名字     造空文件(或刷新时间戳)

写内容(首见重定向):
echo "文字"            → 打印到屏幕
echo "文字" >  file    → 改道写进文件(⚠ 先清空,再写入)
echo "文字" >> file    → 追加到文件末尾(不清空)
```

`less` 生存四键:**Space 下一页 · b 上一页 · `/词` 搜索(n 下一个)· q 退出**。

## 五、上手:读咖啡站,写新菜单

```bash
$ cd ~/coffee-shop && ls
app.jar  config.yml  logs

$ cat config.yml            # 小文件,cat 正合适
shop:
  name: doudou-coffee
  port: 8080

$ head -n 2 logs/app.log    # 日志开头
2026-09-19 10:00:01 INFO  CoffeeApp started on port 8080
2026-09-19 10:00:02 INFO  Menu loaded: 6 items

$ tail -n 1 logs/app.log    # 日志最新一条
2026-09-20 09:12:47 INFO  Health check OK

$ mkdir ~/backup            # 造个备份目录(成功时一声不吭)
$ touch notes.md            # 造个空笔记
$ echo "拿铁 32 元" > menu.txt   # 新菜单第一行
$ cat menu.txt
拿铁 32 元
```

> **特米旁白**:成功时一声不吭,是这个世界的礼貌(Unix 沉默哲学)。`mkdir` 再来一次就会开口了:`mkdir: cannot create directory '/home/ubuntu/backup': File exists`。

## 七、读懂真实「报错」:最可怕的是没有报错

```text
美式 25 元
```

**拿铁没了。** 没有任何报错、退出码还是 0——但第一行菜单被吞了。这是终端里最危险的一类事故:**静默数据丢失**。

根因:`>` 的动作顺序是「**先把目标文件清空,再写入**」。它不是"写进去",是"换掉"。修复:追加要用 `>>`:

```bash
$ echo "拿铁 32 元" > menu.txt     # 重写第一行
$ echo "美式 25 元" >> menu.txt    # >> 追加,不清空
```

> **特米旁白**:`>` `>>` 背后是一整套重定向体系(还有 `2>`、管道 `|`),第 2 卷整卷展开——今天只需刻进肌肉:**对已有文件,想都不想就敲 `>`,等于删档重写。**

> **🪟 双系统对照 · 读与造,Windows 上怎么打**

| 干什么 | Linux (bash) | PowerShell | 备注 |
|---|---|---|---|
| 全倒出来 | `cat file` | `Get-Content file`(别名 `cat`) | 无痛 |
| 看头 / 看尾 | `head -n 5` / `tail -n 5` | `Get-Content file -TotalCount 5` / `-Tail 5` | PS 没有 head/tail 命令 |
| 翻页看 | `less file` | `Get-Content file \| more` | 一样按 q 退出 |
| 造目录 | `mkdir backup` | `New-Item -ItemType Directory backup`(`mkdir` 也能用) | 无痛 |
| 造空文件 | `touch notes.md` | `New-Item -ItemType File notes.md` | PS 没有 touch |
| 覆盖写 | `echo "x" > f` | `"x" > f` | **两边的 `>` 都会先清空**,坑是跨平台的 |

## 八、用命令验证:菜单真的两行都在

终端世界的"单元测试"就是**反问它一遍**,顺便认识一个新朋友——`$?`,**上一条命令的退出码**,0 = 成功,非 0 = 失败:

```bash
$ cat menu.txt
拿铁 32 元
美式 25 元
$ echo $?          # cat 成功了吗
0
$ ls ~/backup      # 目录真的建出来了吗(空目录,无输出,正常)
$ ls -l menu.txt   # 文件大小不是 0,内容真的写进去了
-rw-rw-r-- 1 ubuntu ubuntu 33 Sep 20 10:30 menu.txt
```

# 豆豆 Java 实验室契约

`lib/java-labs.ts` 是第一季前 12 话的公开、版本化实验清单。每个清单绑定稳定 `contentId`、课程/术语/技术版本、允许文件、标准输入、资源上限、断言、知识点、前置条件、错因标签、项目增量与复习间隔。

## 当前公开承诺

- 浏览器实验仅面向 **Java 17 兼容范围**，并标明为“浏览器实验模式”。
- 运行时在用户点击“在浏览器运行”后才可按需加载；阅读页面不得加载它。
- 当前构建尚没有通过验证的 Java 17 Web Worker 运行时，因此按钮不会制造编译或执行结果。学习者可下载 `.java`，或下载 `pom.xml` 与 README 后在 IntelliJ/本地 JDK 中运行。
- Java 25、Maven、JUnit 和多文件工程只在用户 IDE 或未来可选本地运行器中完成，绝不称为“浏览器原生 Java 25”。

## 隐私边界

源码、标准输入、完整控制台输出和本地路径不离开浏览器。OPFS 保存位于 `doudou-java-labs/` 下；浏览器不支持或配额不足时可下载代码。

本地学习证据只允许：匿名随机标识、实验/课程版本、知识点 ID、尝试和时长区间、结果、错因标签及是否使用提示。匿名同步默认关闭；在没有服务端端点的当前版本中，即使用户记录同步意愿也不会发出请求。可导出或清除本地记录与匿名标识。

## 发布门槛

Java 17 Web Worker 适配层或 CheerpJ 只能在以下验证全部通过后接入公开运行按钮：许可与自托管限制、冷启动体积、移动端内存、Java 17 API 覆盖、网络默认关闭、编译/运行取消、OPFS 离线重开，以及前 12 话代表代码的错误定位。未通过时保持“下载到 IDE + 结构化修复实验”的降级路径。

任何未来匿名同步服务必须继续拒绝源码、终端输出、文件路径与设备标识；推荐权重、聚合规则、实验评分、翻译术语维护记录和签名私钥只保存在服务端私有层。中英镜像发布前必须通过 `validateCourseMirrors` 的术语、实验 ID、知识点和代码指纹校验。

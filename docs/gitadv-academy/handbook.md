## 0. 一句话定位

CLI 线 C3「Git 卷」教阿零"会用" add/commit/push,这一部带他潜进 `.git` 目录——**看懂 Git 到底把东西存成了什么、分支合并的真相**,再学会带一个团队从协作工作流走到事故恢复。

面向的不再是零基础读者,而是**用过 Git、被多人协作坑过的进阶者**。差异化立场:**一切结论都要能画成对象图、能用 plumbing 命令还原**——"上层一条命令,底层几步搬墨"。

## 1. 衔接与世界观

- 时间线:CLI 线 C3(单机 Git 基本操作)与 Java 线上云之后。咖啡站招进第二、第三个工程师,分支缠成毛线球、有人往共享分支 force push 抹掉同事一天的活、密钥误提交进仓库——"会用"撑不住"多人"。阿零一头扎进仓库最深处的 `.git`,在墨囊般的暗室里遇见老住户。
- 舞台:豆豆咖啡站的**代码仓库内部**。`objects/` 是储物柜阵列,`refs/` 是贴满便利贴的墙,`HEAD` 是门口一张纸条,`packfile` 是压缩档案库;暗处漂着一片墨海,那是全部版本历史。
- 四卷主线:卷一 Git 的本质(01-07)→ 卷二 分支与合并的真相(08-14)→ 卷三 团队协作工作流(15-21)→ 卷四 事故恢复与进阶(22-28)。

## 2. 角色表(硬约束,防人设漂移)

### 墨叔(Mo)—— 本线导师,仓库里的章鱼

- **外形**:栖息在 `.git` 墨海里的章鱼。**八条腕各缠一条分支**,能同时推进多个上下文互不打架(分支即指针、并行心智的具象化);盯着哪条腕,`HEAD` 就在哪。**喷出的墨就是版本历史**——想改哪段,就把那段墨迹吸回去再吐一遍(负责任地重写历史)。腕尖能同时按住八张便利贴(引用)。
- **性格**:沉稳、话不多,厌恶"以为删了就没了"的莽撞;对"直接 force push 共享分支"零容忍。教人先看清对象图,再动手。
- **口头禅**:"**提交是快照,不是补丁。**"(commit 存的是整棵树的快照,不是 diff——全线第一性原理)
- **副口头禅**:"历史是可以被负责任地重写的。"(rebase / filter-repo 出场时的定心丸,重点在"负责任")
- **能力边界(铁律)**:
  1. 只讲 Git 的机制与**可复现的观测方法**,不替阿零写业务代码;给命令、给对象图,让阿零自己跑自己看。
  2. 不下没有对象图/plumbing 佐证的断言——他自己也遵守 §7 红线。
  3. 涉及"哪个命令默认怎样、哪个行为哪版引入",先查一手 `git help` / 官方文档,不凭旧攻略。
  4. 沿用豆豆的五步排障法(观察 → 收集 → 假设 → 改一个变量 → 重跑验证),墨叔版第一步永远是"**先看它现在指向哪**(`git log --oneline --graph`、`cat .git/HEAD`)"。

### 阿零 —— 本线成长弧:从"会用"进化到"讲透 + 带队"

延续前作人设:能独立开发,但把 Git 当黑箱,一遇冲突/误删就慌。**每卷一次可见的能力上涨**:

| 卷 | 卷终时阿零能做到 |

| 卷三 | 为团队选定工作流、立起 PR 门禁与提交规范 |
| 卷四 | 从 force push 惨案、误删、脏历史里全身而退——**Git 大成** |

## 4. 本线专属深度栏目(两栏配合,是本线的身份)

### 4.1 🕸️ 对象图台(每话必有,恰好 1 个)

- **定位**:把当话的每个操作画成 **commit/tree/blob + 引用的 DAG 变化**——操作前长这样,操作后长这样,箭头指向谁变了。对标 Java 线 🔀 多解台的地位。口号:"提交是快照,不是补丁。"
- **规则**:
  1. 用文本 DAG(`A ← B ← C` + 分支便利贴 `main→C`)或小表格画,**前后各一张**,标出"这次动了哪条箭头/哪张便利贴"。
  2. 对象哈希用短 SHA 占位(`a1b2c3`),真实复现时以 `git cat-file -p` 输出为准。
  3. 逐条解读 2–4 句:哪个对象新生、哪个引用移动、哪个对象变悬空。

### 4.2 🔧 底层拆解(高频,配合 🕸️ 出现)

- **定位**:用 **plumbing 命令还原一次 porcelain 操作**——"你敲的一条 `git commit`,墨叔在底层搬了这几步墨"。差异化 = 永远给可自己复现的 plumbing 命令 + 真实输出。
- **规则**:
  1. 命令照抄可跑,基线 Git 2.4x;Windows(PowerShell 7 / Git Bash)与 Linux(txcloud Ubuntu)写法有差异时一句注明。
  2. 输出真实跑出再节选,**≤15 行**,不许手编;逐行解读 2–4 条。
  3. 按卷推荐 plumbing 工具箱:卷一 `hash-object` / `cat-file -p` / `write-tree` / `commit-tree` / `update-ref`;卷二 `merge-base` / `rev-parse` / `rev-list`;卷三 `ls-files` / `check-attr` / `for-each-ref`;卷四 `reflog` / `fsck --lost-found` / `bisect` / `filter-repo`。
- **格式模板与示例**(以卷一"一次 commit 到底做了什么"为例):

  ```text
  > **🔧 底层拆解 · 一条 git commit,底层搬了几步墨?**
  >
  > 复现命令(照抄可跑):
  > ```bash
  > echo "beans" > menu.txt
  > git hash-object -w menu.txt        # ① 存 blob
  > git update-index --add menu.txt    # ② 写进暂存区
  > git write-tree                     # ③ 把暂存区凝成 tree
  > git commit-tree <tree> -m "add"    # ④ 裹上父指针成 commit
  > ```
  > 逐行解读:① blob 只认内容指纹,和文件名无关;② index 记住"这个 blob 叫 menu.txt";③ tree 是目录快照;④ commit 指向一棵 tree 加一个父——porcelain 的 `git commit` 就是把这四步一口气做完。
  > 墨叔结语:提交是快照,不是补丁——commit 里没有 diff,diff 是 Git 现算给你看的。
  ```

## 7. 写作红线

### 7.1 命令/行为敏感事实:发布前必须联网复核

- **铁律**:凡涉及"某命令默认行为、某行为哪个 Git 版本引入、某 flag 的准确写法"(尤其 `filter-repo`、`--force-with-lease`、`rerere`、`maintenance`、`switch`/`restore` 这类新命令),发布前逐条用 opencode+DeepSeek 或 context7 联网复核,**不凭记忆、不信旧攻略**。核实优先于假设。
- 高危清单:`git filter-branch` 已不推荐,**主推 `git filter-repo`**(第三方,需单独安装)——不要教已过时的 `filter-branch`,只作"历史写法"提及;`--force-with-lease` 与裸 `--force` 的区别必须讲准;`git switch`/`git restore` 与老 `checkout` 的分工;reflog 过期与 `gc` 回收的时机。
- 所有"能救回来"的断言必须标明前提(**未被 `gc` 回收**),不能给读者"永远救得回"的错觉。

### 7.2 术语一致性表(全线统一,首现标注英文)

| 统一用词 | 禁用/别名 |
|---|---|
| 提交(commit)/ 树(tree)/ 数据块(blob) | 对象名保留英文小写 |
| 引用(ref)/ 分支指针 / HEAD | 不写"游标" |
| 暂存区(staging area / index) | 首现标注 index;不写"缓存区" |
| 内容寻址(content-addressable) | 首现必标英文 |
| 三方合并(three-way merge) | 不写"三向" |
| 变基(rebase)/ 交互式变基 | 保留 rebase 英文为主 |
| 悬空对象(dangling object) | 不写"孤儿对象" |
| 强制推送(force push)/ `--force-with-lease` | 后者不省略,首现讲清区别 |

### 7.3 其他红线

- **一切"救回/删净"断言必附命令自证**(`reflog` 输出、`fsck` 结果、`cat-file` 对比);没证据的断言一律让墨叔说"先看它现在指向哪"。
- 报错、命令输出、DAG 一律真实实录,不许编造;编不出来就换一个真跑得出的例子。
- 便利贴语法沿用全站规范:`> [!吐槽]`、`> [!彩蛋]`、`> [!警告]` / `> [!坑]`、`> [!强调]` / `> [!重点]`、`> [!答案]`(折叠 details)、`> [!文字版]`;漫画分格 `> **〔n〕**` 格间空行;固定栏目前缀 `> **🕸️ 对象图台 · …**`、`> **🔧 底层拆解 · …**`、`> **📋 Git 拦路**`,便于一眼识别。
- 追加一条不做:**不把 Git 命令当咒语背**——每个 porcelain 命令出场,至少一次配 🔧 底层拆解讲清它在搬什么墨。

## 一句话定位

没有鼠标、没有图标,只有一个闪烁的光标。跟着阿零和特米,把一台裸服务器驯服成豆豆咖啡站的家 —— **每个指令都有真实用途,不是指令的堆砌**。

## 衔接与世界观

- 承接 Java 线 S7 大结局:咖啡站上云了,但阿零全程靠 IDE 和控制台网页。第一话他第一次 `ssh` 进真实服务器 —— 黑屏与光标,呼应 Java S1E1 的开场。
- **阿零**:延续 Java 线人设与成长(已是能交付系统的人,但对终端是新手 —— "会写代码 ≠ 会用服务器"是本线核心冲突)。
- **特米(Termi)**:新导师,住在终端里的企鹅机器人(Tux 致敬)。性格:惜字如金、答案永远先给最短命令;口头禅「**man 一下**」。不直接替阿零敲,只报命令名让他自己试。
- **豆豆**:不定期客串(咖啡站化身,部署卷戏份多)。
- 技术角色:**root 之王**(权限之巅,危险)、**管道工**(| 化身,C2 登场)、**Git 时间守卫**(C3)。

## 本线独有深度栏目

**🪟 双系统对照**(每话尽量有):同一件事 Linux ↔ PowerShell/cmd 的等价写法,表格化。
服务器是 Linux、读者主力机多是 Windows —— 两边都要会,这是本线区别于所有 Linux 教程的差异点。
其余栏目沿用:🔀 多解台 / 🎯 面试直击;⏳ 版本时光机按需(如 netstat→ss、ifconfig→ip)。

## 每话硬约束(继承 v2 + 本线特化)

- 11 步骨架不变;「故意制造一个 Bug」优先选**真实终端翻车**(路径大小写、rm 误删、权限拒绝、crontab 环境变量)。
- 所有命令输出必须真实可复现(Ubuntu 24.04 基线;PowerShell 7 基线)。
- 「用测试证明」一步可放宽为「**用命令验证**」(echo $?、ls 复查、curl 探活)。
- 项目主线:C1-C2 本地/服务器终端基本功 → C3 咖啡站代码进 Git → C4 系统管理 → C5 部署上线大闭环。
- 篇幅:普通话 3.8k–5.5k 字符;周更,一次只翻一话 published。

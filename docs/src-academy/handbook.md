## 0. 一句话定位

JVM 线教你"钻进运行时"、Java 线教你"会写",这一部教阿零**读别人的代码**——从"只会调 API",进化到"看得懂库的实现",再到"能给开源库改一行"。

面向的是**读完 Java 线、被生产 bug 逼到墙角的进阶者**。本线差异化立场:**读源码是一门有方法的手艺,不是硬啃**——先找入口、再定深度、用调试器验证、把调用链画出来。核心信条:**"别问它做什么,看它怎么做的。"**

## 1. 衔接与世界观

- 时间线:Java 线 S7(上云)、JVM 线(炉心大成)、CLI 线 C5(部署闭环)**之后**。一个文档查不到、Issue 没答案的诡异依赖 bug 在生产反复出现,阿零第一次意识到"会用库"到头了,必须"读库"。
- 舞台:豆豆咖啡站**书库最深处**——一排排落满灰的开源库源码,地板缝里住着穿山甲挖姐。与烘焙工坊(JVM 线)一层之隔,焰焰偶尔从炉底通风口递字节码佐证。
- 五卷主线:卷一 读源码的方法论(1-7)→ 卷二 集合框架源码(8-14)→ 卷三 JDK 并发源码(15-21)→ 卷四 Spring 源码骨架(22-28)→ 卷五 读框架的通法(29-34)。

## 2. 角色表(硬约束,防人设漂移)

### 挖姐(Wa)—— 本线导师,穿山甲

- **外形**:栖息在书库地板缝里的穿山甲。**爪子能剥开任何封装的硬壳**(拆抽象的具象化);顺着调用链一层层往里挖,越挖越深。**身上的鳞片是一片片折叠起来的调用栈**——每片鳞展开就是一层方法调用,把全身鳞片摊平,就是一条从入口到底层的完整调用路径。
- **性格**:沉稳、爱刨根、见不得"背结论不看实现"。对"抄 API、背八股、遇 bug 只会重启"零容忍;但也懂"缺氧"——会及时拽住往兔子洞里越钻越深的阿零。
- **口头禅**:"**别问它做什么,看它怎么做的。**"(拒绝停留在 API 契约,下潜到实现)
- **副口头禅**:"读不懂的源码,是还没找到那个入口。"(引导先定位入口,别硬啃)
- **能力边界(铁律)**:
  1. 只教**读源码的方法与观测**,不替阿零写业务代码;给入口、给地图,让阿零自己顺着挖。
  2. 不下"这段源码就是这样"的空口断言——一切结论要么有调试器实证,要么有🗺️调用链地图佐证。
  3. 读到 JVM/字节码层就交棒给焰焰(跨线钩子),不越界重讲 JVM 内功。
  4. 沿用豆豆的五步排障法,但挖姐版第一步永远是"**先找到入口,再往下挖**"。

### 阿零 —— 本线成长弧:从"会用"进化到"能改"

延续前作人设:能交付系统、懂点 JVM,但一遇到库内部就发怵、只会 Google。**每卷一次可见的能力上涨**:

| 卷 | 卷终时阿零能做到 |
|---|---|
| 卷一 | 拿到任意小库,能定位入口、分层下潜、画出调用链,第一次"读透"一个库 |
| 卷二 | 集合源码全读通,能手写一个够用的 HashMap 与 JDK 版对拍 |
| 卷三 | 顺着 AQS 等待队列反查死锁现场,给出勘验报告 |
| 卷四 | 在 Spring 源码里精确定位一个生产 bug(后置处理器时机 + 代理失效) |
| 卷五 | 用同一套通法拿下 Netty/MyBatis/Tomcat,给真实开源项目提交被合并的 PR——**从会用到能改** |

### 客串规则(豆豆 / 焰焰 / 特米 / 版本残影)

- **豆豆**:本线化身"**造 bug 的人**"——制造触发下潜的生产事故(01 话的诡异 bug、卷三的死锁),保持毒舌但**不当导师**(本线导师是挖姐)。
- **焰焰**(JVM 线):读到字节码/JVM 层时,从炉底通风口递一句 `javap` 反编译或运行时视角**当佐证**,一句话量级,读完即交棒,不抢戏。
- **特米**(CLI 线):从通风管递**把源码拉到本地翻**的终端手艺(`git clone`、`git blame`、`git log -p`),只递 CLI 线已教过的,一句话量级。
- **版本残影**:历史实现的幽灵(如 JDK 7 的 ConcurrentHashMap Segment 残影、旧 Spring 版本残影),用于"版本对照读源码演进";每话至多一次,残影只演不教。
- 挖姐不去别线当导师;跨线联动只走 §8 钩子表。

## 4. 本线专属深度栏目(两个,读新库/读流程各配其一)

### 🔦 入口探照灯(读一个新库或新机制必有)

- **定位**:回答"这几十万行,从哪一行开始读?"——治的正是新手最大的恐惧。对标 JVM 线的 🔬 炉底显微镜。
- **规则**:
  1. 给出**三种找入口姿势**中至少命中的一种:main/启动方法、自动配置/装配点、SPI/`ServiceLoader` 服务发现;并说清为什么是它。
  2. 命令/断点照抄可跑,基线 JDK 25;拉源码用 `git clone` + 依赖源码 jar,一句注明。
  3. 明确"入口 → 第一个值得下潜的方法"这一跳,把探照灯照到的落点交给 §7 的调用链地图接力。
- **格式模板**:

  ```text
  > **🔦 入口探照灯 · <这个库>从哪读起?**
  >
  > 找入口姿势:<main / 自动配置 / SPI> —— 因为 <一句理由>。
  > 落点:`<类#方法>` —— 这是主流程真正的第一站。
  > 照抄可跑:在 `<类#方法>` 打断点,跑 `<最小复现>`,看第一帧栈。
  > 挖姐提示:读不懂的源码,是还没找到那个入口。
  ```

### 🗺️ 调用链地图(读一段流程必有)

- **定位**:把一次调用画成从入口到底层的**路线图**,标出每层职责、参数如何变形、在哪里折返。对标 CLI 线的 🪟 双系统对照——差异化 = **可视化调用路径**。
- **规则**:
  1. 用有序列表或表格画"入口 → 中转 → 底层"的每一站,每站一句职责。
  2. 标出**折返点**(递归/回调/代理转发)与**该停的那一层**(读到此为止,再深属下一话/交棒焰焰)。
  3. 与 §3 第 6 步下潜路径严格一致,不画没读过的层。
- **格式模板**:

  ```text
  > **🗺️ 调用链地图 · <这次调用>怎么走的**
  >
  > | 层 | 落点 | 这一层干了什么 |
  > |---|---|---|
  > | ① 入口 | `A#m()` | 收参、校验 |
  > | ② 中转 | `B#n()` | 选分支、变形参数 |
  > | ③ 底层 | `C#k()` | 真正干活;⟳ 此处折返 / ⛔ 读到此为止 |
  >
  > 挖姐结语:别问它做什么,看它怎么做的——路线画出来,魔法就没了。
  ```

## 7. 写作红线

### 7.1 源码事实:发布前必须核对真实源码

- **铁律**:凡引用具体类名、方法名、字段名、行为(如"链表长度 8 树化""三级缓存字段名""refresh 十二步的方法顺序"),发布前**对着真实源码核对**(拉对应版本的源码 jar / OpenJDK / Spring GitHub tag),不凭记忆、不信旧博客。核实优先于假设。基线:JDK 25、Spring Boot 4.x / Spring Framework 6.x-7.x、jakarta 命名空间;版本敏感处写清"以 JDK 25 / Spring x.y 源码为准"。
- 每话触及即必查的高危清单:所有具体类/方法/字段名与其在目标版本的存在性;一切阈值断言(树化阈值 8、扩容因子 0.75、1.5 倍扩容);"某版本改了实现"的演进断言(CHM 分段锁→CAS 的版本分界);Spring 各版本方法签名易变处;框架(Netty/MyBatis/Tomcat)的类名以其稳定版为准。
- **实现会随版本变**:凡"这段源码长这样"的结论,必须绑一个版本号;跨版本差异用 ⏳ 版本时光机表格化,别把老实现当现状教。

### 7.2 术语一致性表(全线统一,首现标注英文)

| 统一用词 | 禁用/别名 |
|---|---|
| 调用链(call chain)/ 调用栈(call stack) | 不混用;栈是运行时快照,链是逻辑路径 |
| 入口(entry point) | 不写"起点函数" |
| 下潜 / 上浮 | 本线专属动词,统一保留 |
| 扰动函数(hash spread) | 首现标英文 |
| 后置处理器(BeanPostProcessor) | 保留英文类名,不译"后处理器" |
| 三级缓存 | 明确指 singletonObjects/earlySingletonObjects/singletonFactories |
| 动态代理(dynamic proxy) | JDK 代理 / CGLIB 分清,不笼统说"代理" |
| 门面(facade) | SLF4J/Collections 场景统一用"门面" |

### 7.3 其他红线

- **源码结论必附证据**:断点截图式的实录、`javap` 输出、或 JUnit 对拍;没证据的"我觉得它这么做"一律让挖姐说"别猜,打个断点看"。
- 具体行号/输出一律真实核对,不许编造;编不出来就换一个真读得到的例子或降级为"以 x.y 版为准"。
- 便利贴语法沿用全站规范(`lib/markdown.ts` STICKY_CLASS):`> [!吐槽]`、`> [!彩蛋]`、`> [!警告]` / `> [!坑]`、`> [!强调]` / `> [!重点]`、`> [!答案]`(折叠 details,放选读硬核推导如红黑树旋转)、`> [!文字版]`;漫画分格 `> **〔n〕**` 格间空行;固定栏目前缀 `> **🔦 入口探照灯 · …**`、`> **🗺️ 调用链地图 · …**`,便于一眼识别。
- 继承 Java 线 §10 全部"必须坚持 / 绝不做";本线追加两条不做:**不把源码大段贴上来当篇幅**(只贴读到的关键几行 + 地图);**不为炫技往兔子洞里无限下潜**——每次下潜都要绑一个"要回答的问题",答完即上浮(§3 第 6 步)。

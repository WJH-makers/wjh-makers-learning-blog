# 《从零开始学 Java》07 · 多杯订单:数组

> 第一季「点火篇」第 7 话 · 承接:会循环、但菜单是散装变量的咖啡站。

---

## 一、需求:把整张菜单排成一排

菜单现在是 `name1 / name2 / name3` 三个独立变量,想「打印整张菜单」只能一个个手写。得把它们排进一个能**按顺序、按下标**取用的容器 —— 数组。

---

## 二、漫画

> **〔1〕** 数组村是一排编号从 0 开始的储物格:`[0][1][2]`。
> 豆豆:「数组下标**从 0 开始**,3 个格子的合法下标是 0、1、2。」

> **〔2〕** 阿零去取「第 3 个」写成了下标 3,伸手扑了个空,摔进格子外。
> 豆豆:「越界!下标 3 已经在 3 个格子**之外**了。」

---

## 三、本话目标

- 声明并初始化数组;
- 用普通 for 和 for-each 遍历;
- 用 `Arrays.toString` 快速打印;
- 踩一次 `ArrayIndexOutOfBoundsException`。

## 四、原理图

```text
double[] prices = {15.0, 18.0, 20.0};
下标            0     1     2       长度 prices.length == 3
合法下标范围:0 .. length-1
```

---

## 五、代码:遍历菜单

```java
import java.util.Arrays;

public class Cafe {
    public static void main(String[] args) {
        String[] menu = {"美式", "拿铁", "卡布奇诺"};
        double[] prices = {15.0, 18.0, 20.0};

        // 普通 for:需要下标时用
        for (int i = 0; i < menu.length; i++) {
            System.out.println((i + 1) + ". " + menu[i] + " ¥" + prices[i]);
        }

        // for-each:只关心元素、不关心下标时用
        double sum = 0;
        for (double p : prices) sum += p;
        System.out.println("整单打包价 ¥" + sum);
        System.out.println(Arrays.toString(prices));
    }
}
```

---

## 六、故意制造一个 Bug

「取第 3 个价格」写成下标 3:

```java
System.out.println(prices[3]);   // ← 故意越界,合法下标只到 2
```

---

## 七、读懂真实报错

```text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException:
        Index 3 out of bounds for length 3
        at Cafe.main(Cafe.java:12)
```

`Index 3 out of bounds for length 3` —— 长度是 3,合法下标 0~2,下标 3 已越界。注意这是**运行期**异常(编译能过),编译官管不了下标,得靠自己守住 `0 .. length-1`。

---

## 八、修复,并用测试证明

想取「最后一个」,用 `length - 1`。把「整单合计」抽成方法:

```java
static double totalOf(double[] prices) {
    double sum = 0;
    for (double p : prices) sum += p;
    return sum;
}
```

```java
@Test
void total_of_menu() {
    assertEquals(53.0, Cafe.totalOf(new double[]{15.0, 18.0, 20.0}));
}
```

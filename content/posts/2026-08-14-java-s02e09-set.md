# 《从零开始学 Java》21 · Set 会员去重

> 第二季「对象大陆」第 9 话 · 基线 JDK 25 · 承接:第 19 话的判等契约 + 第 20 话的 List。

---

## 一、需求:会员名单自动去重

同一位会员被重复登记。想要一个「放进去重复的自动消失」的容器 —— `Set`。

---

## 二、漫画

> **〔1〕** 一道门写着 `HashSet`,进门先按 `hashCode` 分到桶,再用 `equals` 比对。
> 豆豆:「先按哈希找桶,再在桶里用 equals 确认 —— 两步都对上才算重复。」

> **〔2〕** 阿零的 Member 没写 `hashCode`,两个「张三」被分到不同桶,都留下了。
> 豆豆:「所以上一话强调:进 Set/Map 的对象,equals 和 hashCode 必须成对。」

---

## 三、本话目标

- 用 `Set<T>` / `HashSet` 自动去重;
- 理解 HashSet 去重依赖 `hashCode` + `equals`;
- 认识 `TreeSet`(有序)与 `LinkedHashSet`(保持插入顺序);
- 踩一次「元素没正确实现 hashCode,去重失效」。

---

## 四、原理图

```text
Set 不允许重复。HashSet 判重复:
  1) 算 hashCode → 定位到某个桶
  2) 桶里逐个 equals 比对 → 相等则视为已存在,不再加入

hashCode 不一致 → 分到不同桶 → 永远比不到一起 → 去重失效
TreeSet 按大小排序;LinkedHashSet 保持插入顺序
```

## 五、代码:会员去重(用 record 保证契约)

```java
import java.util.HashSet;
import java.util.Set;

record Member(String id, String name) {}   // record 自动给出正确的 equals/hashCode

public class Members {
    public static void main(String[] args) {
        Set<Member> members = new HashSet<>();
        members.add(new Member("m01", "张三"));
        members.add(new Member("m01", "张三"));   // 重复,自动被丢弃
        members.add(new Member("m02", "李四"));

        System.out.println("去重后 " + members.size() + " 人");   // 2
    }
}
```

---

## 六、故意制造一个 Bug

把 `record` 换成一个「只写了 equals、没写 hashCode」的普通类:

```java
class Member {
    final String id;
    Member(String id) { this.id = id; }
    @Override public boolean equals(Object o) {
        return o instanceof Member m && id.equals(m.id);
    }
    // 缺 hashCode
}
```

再放两个相同 id 进 HashSet。

---

## 七、读懂现象(去重失效)

`members.size()` 输出 `2` 而不是 `1` —— 不报错,但去重没生效。两个相等的对象因为 `hashCode` 默认按对象地址算、各不相同,被分进不同桶,永远碰不到一起做 `equals`。**这就是第 19 话埋的雷在此引爆**。修法:补 `hashCode`,或干脆用 `record`。

---

## 八、修复,并用测试证明

```java
@Test
void hashset_dedupes_by_contract() {
    var set = new HashSet<Member>();
    set.add(new Member("m01", "张三"));
    set.add(new Member("m01", "张三"));
    assertEquals(1, set.size());   // record 契约齐全,去重成立
}
```

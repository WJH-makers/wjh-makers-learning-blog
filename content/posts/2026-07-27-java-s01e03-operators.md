# 《从零开始学 Java》03 · 咖啡价格计算器

> 第一季「点火篇」第 3 话 · 承接:能记住单价和库存的咖啡站。

---

## 一、需求:算总价和找零

顾客点 3 杯美式,给了 50 元。总价多少?找零多少?咖啡站得会算。

---

## 二、漫画

> **〔1〕** 运算街两侧挂满招牌:`+ - * / %`。
> 豆豆:「`*` 是乘,`/` 是除,`%` 是取余数。」

> **〔2〕** 阿零算「平均每杯」时用了两个整数相除,结果小数没了。
> 豆豆:「这就是**整数除法**的坑 —— 两个 `int` 相除,结果还是 `int`,小数直接被砍掉。」

---

## 三、本话目标

- 用算术运算符算总价、找零、平均价;
- 理解 `%` 取余;
- 踩一次「整数除法丢精度」的逻辑坑并修好;
- 用比较 / 逻辑运算符判断「够不够买」。

---

## 四、原理图

```text
算术  +  -  *  /  %(取余)
比较  >  <  >=  <=  ==  !=      结果是 boolean
逻辑  &&(与)  ||(或)  !(非)     短路求值
```

陷阱:`5 / 2` == `2`(两个 int,砍掉小数);要小数得让至少一个是 `double` → `5.0 / 2` == `2.5`。

---

## 五、代码:算价与找零

```java
public class Cafe {
    public static void main(String[] args) {
        double price = 15.0;   // 单价
        int qty = 3;           // 杯数
        double paid = 50.0;    // 顾客付款

        double total = price * qty;      // 总价 45.0
        double change = paid - total;    // 找零 5.0
        boolean enough = paid >= total;  // 够不够付

        System.out.println("总价 ¥" + total + " · 找零 ¥" + change + " · 付款充足:" + enough);
    }
}
```

---

## 六、故意制造一个 Bug

想算「人均消费」:3 杯 45 元,4 个人一起付,人均多少?

```java
int people = 4;
int avg = (int) total / people;   // ← 期望 11.25,却得到 11
System.out.println("人均 ¥" + avg);
```

---

## 七、读懂现象(这是逻辑 Bug,不报错)

程序照跑不误,但结果 `人均 ¥11` 是错的 —— 这类**能运行、结果却不对**的叫 **Logic Bug**,编译官不会拦你,得靠自己发现。

原因:`avg` 是 `int` 盒子,`11.25` 被砍成 `11`。精度在赋值给 `int` 的那一刻就没了。

---

## 八、修复,并用测试证明

用 `double` 保留小数:

```java
static double perPerson(double total, int people) {
    return total / people;   // total 是 double,结果就是 double
}
```

```java
@Test
void split_45_among_4() {
    assertEquals(11.25, Cafe.perPerson(45.0, 4));
}
```

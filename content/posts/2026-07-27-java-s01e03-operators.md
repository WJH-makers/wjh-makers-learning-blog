- 用比较 / 逻辑运算符判断「够不够买」。

## 四、原理图

```text
算术  +  -  *  /  %(取余)
比较  >  <  >=  <=  ==  !=      结果是 boolean
逻辑  &&(与)  ||(或)  !(非)     短路求值
```

陷阱:`5 / 2` == `2`(两个 int,砍掉小数);要小数得让至少一个是 `double` → `5.0 / 2` == `2.5`。

**短路求值**顺带记一下:`&&` 左边为 `false` 就不看右边,`||` 左边为 `true` 就不看右边 —— 后面判空、防越界都靠它「先挡一道再往下走」。

> **豆豆旁白**:别小看 `%` 取余,它是运算街最能干的杂工。「第 N 位顾客免单」用 `n % 10 == 0`;「判断奇偶」用 `n % 2`;「让编号在 0~len 之间循环」用 `i % len`。凡是「转圈、跳格、每逢整数就触发」的需求,先想想它。

## 五、代码:算价与找零

```java
public class Cafe {
    public static void main(String[] args) {
        double price = 15.0;   // 单价
        int qty = 3;           // 杯数
        double paid = 50.0;    // 顾客付款

        double total = price * qty;      // 总价 45.0
        double change = paid - total;    // 找零 5.0
        boolean enough = paid >= total;  // 够不够付

        System.out.println("总价 ¥" + total + " · 找零 ¥" + change + " · 付款充足:" + enough);
    }
}
```

光「钱够」还不够,还得「有货」才能出杯 —— 两个条件同时成立,用逻辑与 `&&` 串起来:

```java
int stock = 2;                                   // 库存 2 杯
boolean canServe = enough && stock >= qty;       // 钱够 且 货够,才出杯
```

`&&` 还顺带帮你**防空转**:如果 `enough` 是 `false`,右边 `stock >= qty` 根本不会去算(短路)。等以后右边是「查数据库」这种昂贵操作时,这一下短路能省下真金白银。

## 六、故意制造一个 Bug

想算「人均消费」:3 杯 45 元,4 个人一起付,人均多少?

```java
int people = 4;
int subtotal = 45;               // 3 杯共 45 元(先用整数演示整除)
int avg = subtotal / people;     // ← 期望 11.25,实际得到 11
System.out.println("人均 ¥" + avg);
```

---

## 七、读懂现象(这是逻辑 Bug,不报错)

程序照跑不误,但结果 `人均 ¥11` 是错的 —— 这类**能运行、结果却不对**的叫 **Logic Bug**,编译官不会拦你,得靠自己发现。

最常见的错觉是「`11.25` 被塞进 `int` 盒子、砍成了 `11`」。**但 `11.25` 从来没被算出来过。** `subtotal` 和 `people` 都是 `int`,`45 / 4` 走的是**整数除法** —— 在做除法的那一步,小数部分就被直接丢弃,直接得 `11`。

一句话钉死:**丢精度发生在「除法」本身,不是「赋值」那一刻。**

---

## 八、修复,并用测试证明

用 `double` 保留小数:

```java
static double perPerson(double total, int people) {
    return total / people;   // total 是 double,结果就是 double
}
```

> **豆豆锐评**:只要除号两边**有一个是小数**,Java 就会把另一个也自动提升成 `double` 再算,小数就保住了 —— 这叫**类型提升**。`45.0 / 4` 得 `11.25`,`45 / 4` 得 `11`,差一个点,差一场投诉。

```java
@Test
void split_45_among_4() {
    assertEquals(11.25, Cafe.perPerson(45.0, 4));
}
```

> **🎯 面试直击**:`System.out.println(5 / 2)` 和 `5 % 2` 各输出什么?
> 分别是 `2` 和 `1`。`/` 对两个 `int` 是整除(砍小数,不四舍五入),`%` 取余数。追问防身:① 想要 `2.5`,把任一操作数写成 `double`(`5.0 / 2`),靠类型提升保精度;② `%` 还能判奇偶(`n % 2 == 0`)、做环形编号(`i % len`);③ 陷阱升级:`5 / 0` 抛 `ArithmeticException`,但 `5.0 / 0` 不抛,得到 `Infinity` —— 整数除零炸、浮点除零不炸,这一对经常连着考。

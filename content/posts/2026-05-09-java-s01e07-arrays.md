## 三、本话目标

- 声明并初始化数组;
- 用普通 for 和 for-each 遍历;
- 用 `Arrays.toString` 快速打印;
- 记牢 off-by-one:第 1 个在 0 号、最后一个在 `length - 1`;
- 踩一次 `ArrayIndexOutOfBoundsException`。

---

## 四、原理图

```text
double[] prices = {15.0, 18.0, 20.0};
下标            0     1     2       长度 prices.length == 3
合法下标范围:0 .. length-1        ← 想要「最后一个」永远是 length-1
```

`prices.length` 是**数组自带的一个字段**(注意:没有括号),它记着这排格子有几个。合法下标从 `0` 到 `length - 1`,伸手够到 `length` 就摔出围栏。数组一旦建好,`length` 就**定死了**、不能再改 —— 想加菜得换更大的数组,这也是第二季要请出 `List` 的原因。

## 五、代码:遍历菜单

```java
import java.util.Arrays;

public class Cafe {
    public static void main(String[] args) {
        String[] menu = {"美式", "拿铁", "卡布奇诺"};
        double[] prices = {15.0, 18.0, 20.0};

        // 普通 for:需要下标时用(注意 i < length,不是 <=)
        for (int i = 0; i < menu.length; i++) {
            System.out.println((i + 1) + ". " + menu[i] + " ¥" + prices[i]);
        }

        // for-each:只关心元素、不关心下标时用(上一话预告过的那个)
        double sum = 0;
        for (double p : prices) sum += p;
        System.out.println("整单打包价 ¥" + sum);
        System.out.println(Arrays.toString(prices));
    }
}
```

普通 `for` 的条件是 `i < menu.length` 而**不是** `i <= menu.length` —— 差这一个等号,就会在最后多够一次、摔出围栏。这正是 off-by-one 最常见的犯案现场。

## 六、故意制造一个 Bug

「取第 3 个价格」写成下标 3:

```java
System.out.println(prices[3]);   // ← 故意越界,合法下标只到 2
```

## 七、读懂真实报错

```text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException:
        Index 3 out of bounds for length 3
        at Cafe.main(Cafe.java:12)
```

`Index 3 out of bounds for length 3` —— 长度是 3,合法下标 0~2,下标 3 已越界。注意这是**运行期**异常(编译能过),编译官管不了下标,得靠自己守住 `0 .. length-1`。报错还贴心地给了 `at Cafe.main(Cafe.java:12)` —— 直接告诉你摔在第 12 行,顺着去改就行。

## 八、修复,并用测试证明

想取「最后一个」,用 `length - 1`。把「整单合计」抽成方法:

```java
static double totalOf(double[] prices) {
    double sum = 0;
    for (double p : prices) sum += p;
    return sum;
}
```

```java
@Test
void total_of_menu() {
    assertEquals(53.0, Cafe.totalOf(new double[]{15.0, 18.0, 20.0}));
}
```

> **🎯 面试直击**:`length`、`length()`、`size()` 有什么区别?
> 一句话分清:**数组**取长度用字段 `arr.length`(无括号);**String** 取长度用方法 `s.length()`(有括号);**集合**(`List`/`Set`/`Map`,第二季登场)取元素个数用方法 `.size()`。追问防身:为什么数组是字段、String 是方法?数组长度是 JVM 在创建时就定死的**只读属性**,直接暴露成字段;String 的长度要由内部字符数据算出,封装成方法更合理。三者混用是最高频的「找茬」笔试题,写错一个括号就露馅。

## 🎯 随堂练习

先自己做,再对答案。每道答案都带一句「举一反三」,帮你把这一个点连成一片。

### 选择题(10 道)

1. `double[] prices = {15.0, 18.0, 20.0};` 的合法下标范围是?
   - A) `1 ~ 3`　B) `0 ~ 3`　C) `0 ~ 2`　D) `0 ~ prices.length`
2. `System.out.println(prices[3]);` 会?
   - A) 编译报错　B) 运行期抛 `ArrayIndexOutOfBoundsException`　C) 输出 `0.0`　D) 输出 `null`
3. 取「最后一个元素」的正确写法是?
   - A) `arr[arr.length]`　B) `arr[arr.length - 1]`　C) `arr[-1]`　D) `arr.last()`
4. `length`、`length()`、`size()` 的正确归属是?
   - A) 数组 `length`、String `length()`、集合 `size()`　B) 数组 `length()`、String `length`、集合 `size()`　C) 三者可以互换　D) 数组 `size()`、String `length()`、集合 `length`
5. 普通 for 里把 `i < menu.length` 写成 `i <= menu.length`,后果是?
   - A) 少遍历一个元素　B) 最后多够一次,越界抛异常　C) 编译报错　D) 没有影响
6. 数组一旦创建,它的 `length`?
   - A) 可以随时扩容　B) 定死了不能改,想加菜得换更大的数组　C) 会随赋值自动增长　D) 只能变小
7. 「只关心元素、不关心下标」时最合适的遍历方式是?
   - A) 普通 `for` 配下标　B) `for-each`　C) `while` 手动维护下标　D) `do-while`
8. `Arrays.toString(prices)` 的作用是?
   - A) 把数组转成真正的字符串数组　B) 把数组内容格式化成可读的一行,方便打印调试　C) 排序后再打印　D) 把每个元素转成 String 类型
9. 数组越界是在什么时候被发现的?
   - A) 编译期,编译官会拦　B) 运行期,由 JVM 抛异常　C) 写代码时 IDE 一定会报红　D) 永远不会被发现
10. 「差一错误(off-by-one)」指的是?
    - A) 数组长度算错了 1　B) 序号从 1 数、下标从 0 数,两者永远差 1 导致的错位　C) 循环少跑一次　D) 浮点数精度误差

> [!答案]
> **1-C**　3 个格子编号 0、1、2,没有 3 号格。**举一反三**:「合法下标 `0 .. length-1`」这一句能省你半辈子越界。
> **2-B**　编译能过,运行时才摔出围栏:`Index 3 out of bounds for length 3`。**举一反三**:报错里还带 `at Cafe.main(Cafe.java:12)`,顺着行号直接去改。
> **3-B**　最后一个永远是 `length - 1`。**举一反三**:Java 没有 Python 的 `arr[-1]`,负下标同样越界。
> **4-A**　数组是字段(无括号),String 和集合是方法(有括号)。**举一反三**:数组长度是创建时定死的只读属性,所以暴露成字段;这是笔试找茬题常客。
> **5-B**　`i` 最后会等于 `length`,正好够到围栏外。**举一反三**:差一个等号就是一次事故,这正是 off-by-one 最常见的犯案现场。
> **6-B**　数组长度创建即定死。**举一反三**:这正是第二季请出 `List` 的原因 —— 要能动态增删,就得换容器。
> **7-B**　`for-each` 专门「逐个取出、不管下标」。**举一反三**:需要下标(打印序号、按位置改元素)时还得用普通 `for`。
> **8-B**　直接 `println(数组)` 只会打印出类似 `[D@1b6d3586` 的地址,`Arrays.toString` 才给你看内容。**举一反三**:二维数组要用 `Arrays.deepToString`,这一对经常一起考。
> **9-B**　编译官管不了下标,只有运行时 JVM 才知道数组多长。**举一反三**:凡是「值相关」的错误(越界、除零、空指针)都在运行期,编译期只管类型。
> **10-B**　「第 1 个」住在 0 号格,「第 3 个」住在 2 号格。**举一反三**:循环边界、分页起止、截取字符串,off-by-one 会在整个职业生涯里反复来找你。

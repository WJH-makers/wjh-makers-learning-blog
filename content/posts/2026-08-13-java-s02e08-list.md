## 一、需求:一个能自动伸缩的订单容器

数组长度固定:开小了装不下高峰订单,开大了平时浪费。需要一个**能随订单增减自动伸缩**的容器 —— `List`。

---

## 二、漫画

> **〔1〕** 一条能自己接长的传送带,标着 `ArrayList`。订单一多,它自动延长。
> 豆豆:「`ArrayList` 底层是会自动扩容的数组;`LinkedList` 是链表,两头增删快。」

> **〔2〕** 阿零一边遍历订单一边往外扔,传送带突然卡死报警。
> 豆豆:「一边遍历一边改结构,集合会翻脸 —— ConcurrentModificationException。」

## 三、本话目标

- 用 `List<T>` / `ArrayList` 增删改查、遍历;
- 了解 `ArrayList`(数组)与 `LinkedList`(链表)的取舍;
- 踩一次遍历中删除的 `ConcurrentModificationException`;
- 学会用迭代器 `removeIf` 安全删除。

## 四、原理图

```text
List<String> orders = new ArrayList<>();
orders.add("美式"); orders.get(0); orders.size(); orders.remove("美式");

ArrayList   随机访问快(按下标),中间增删要挪元素
LinkedList  两端增删快,随机访问慢
遍历中改结构 → ConcurrentModificationException;用 removeIf / 迭代器
```

## 五、代码:订单队列

```java
import java.util.ArrayList;
import java.util.List;

public class Orders {
    public static void main(String[] args) {
        List<String> orders = new ArrayList<>();
        orders.add("美式");
        orders.add("拿铁");
        orders.add("美式");

        System.out.println("共 " + orders.size() + " 单");
        for (String o : orders) System.out.println("制作 " + o);
    }
}
```

## 六、故意制造一个 Bug

想在遍历时把所有「美式」取消:

```java
for (String o : orders) {
    if (o.equals("美式")) orders.remove(o);   // ← 故意:for-each 中改结构
}
```

---

## 七、读懂真实报错

```text
Exception in thread "main" java.util.ConcurrentModificationException
        at java.base/java.util.ArrayList$Itr.checkForComodification(ArrayList.java:1095)
        at Orders.main(Orders.java:12)
```

`ConcurrentModificationException` —— for-each 底层用迭代器,它记录了集合的「修改次数」;你绕过迭代器直接 `remove`,次数对不上,它立刻抛异常,防止你在不一致的状态上继续。

---

## 八、修复,并用测试证明

用 `removeIf`(专为「按条件删除」设计,内部安全):

```java
static int cancelAll(List<String> orders, String name) {
    int before = orders.size();
    orders.removeIf(o -> o.equals(name));   // 安全删除
    return before - orders.size();          // 取消了几单
}
```

```java
@Test
void cancel_all_americano() {
    var orders = new ArrayList<>(List.of("美式", "拿铁", "美式"));
    assertEquals(2, Orders.cancelAll(orders, "美式"));
    assertEquals(1, orders.size());
}
```

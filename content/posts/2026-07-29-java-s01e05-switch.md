# 《从零开始学 Java》05 · 菜单选择:switch

> 第一季「点火篇」第 5 话 · 承接:会判断余额、但菜单只有一种咖啡的咖啡站。

---

## 一、需求:按编号点单

菜单有:1 美式、2 拿铁、3 卡布奇诺。顾客输入编号,咖啡站报出名称和价格。用 `if-else` 叠三层已经开始乱了。

---

## 二、漫画

> **〔1〕** 一台分拣机,顶上一个投币口写着 `switch`,下面 3 个出口标着 `case 1 / 2 / 3`。
> 豆豆:「`switch` 按值分拣,比一长串 `if-else` 清爽。」

> **〔2〕** 阿零用老式写法漏了 `break`,球一路滚穿了好几个出口。
> 豆豆:「老式 `switch` 不写 `break` 会**穿透**到下一个 case —— 经典事故。」

---

## 三、本话目标

- 用 `switch` 替代成串的 `if-else`;
- 理解老式 `switch` 的 `break` 与「穿透」;
- 用 Java 现代箭头 `switch`(`->`)彻底避免穿透。

---

## 四、原理图

```text
老式:  switch (值) { case A: ...; break; default: ...; }   忘 break 就穿透
现代:  名称 = switch (值) { case A -> ...; default -> ...; };  箭头,不穿透,还能返回值
```

---

## 五、代码:按编号报价(现代写法)

```java
public class Cafe {
    static double priceOf(int choice) {
        return switch (choice) {
            case 1 -> 15.0;   // 美式
            case 2 -> 18.0;   // 拿铁
            case 3 -> 20.0;   // 卡布奇诺
            default -> throw new IllegalArgumentException("没有编号 " + choice);
        };
    }

    public static void main(String[] args) {
        int choice = 2;
        System.out.println("编号 " + choice + " → ¥" + priceOf(choice));
    }
}
```

---

## 六、故意制造一个 Bug(老式写法)

换成老式 `switch`,并「手滑」漏掉 `break`:

```java
double price = 0;
switch (choice) {           // choice = 1
    case 1: price = 15.0;   // ← 漏了 break
    case 2: price = 18.0;   // 穿透到这里,被覆盖
    case 3: price = 20.0;   // 又被覆盖
}
System.out.println(price);  // 期望 15.0,实际 20.0
```

---

## 七、读懂现象(又是 Logic Bug)

不报错,但点「美式(1)」却收了「卡布奇诺(20 元)」的钱。因为 `case 1` 命中后没 `break`,程序**继续往下穿透**,`price` 被 18、20 依次覆盖。

---

## 八、修复,并用测试证明

回到箭头 `switch`(结构上就不可能穿透)。用测试锁死每个编号的价:

```java
@Test
void price_matches_menu() {
    assertEquals(15.0, Cafe.priceOf(1));
    assertEquals(18.0, Cafe.priceOf(2));
    assertEquals(20.0, Cafe.priceOf(3));
}
```

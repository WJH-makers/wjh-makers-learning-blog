# 《从零开始学 Java》04 · 余额不足:if

> 第一季「点火篇」第 4 话 · 承接:会算价、但不会拒绝的咖啡站。

## 一、需求:钱不够就别做

上一话不管付没付够,咖啡照做。得让咖啡站**做判断**:够钱才出杯,不够就提示。

## 二、漫画

> **〔1〕** 判断城门口一个岔路,门卫豆豆举牌:`if ( 条件 )`。
> 豆豆:「条件为 `true` 走这边,`false` 走那边。」

> **〔2〕** 阿零把「等于」写成一个等号 `=`,门卫脸色一变。
> 豆豆:「`=` 是**赋值**(把右边塞进左边),`==` 才是**比较**。写错这一个字符,坑过无数人。」

---

## 三、本话目标

- 用 `if / else` 让程序分支;
- 分清 `=`(赋值)和 `==`(比较);
- 用三元运算符写简洁的二选一;
- 踩一次 `if (a = b)` 的编译错误。

---

## 四、原理图

```text
if (条件) {
    // 条件为 true 时执行
} else {
    // 否则执行
}

三元:  结果 = 条件 ? 值A : 值B ;
```

`==` 比较两个值是否相等,结果是 `boolean`;`=` 是把右边赋给左边。`if(...)` 里要的是 `boolean`。

---

## 五、代码:够钱才出杯

```java
public class Cafe {
    public static void main(String[] args) {
        double total = 45.0;
        double paid = 30.0;

        if (paid >= total) {
            System.out.println("出杯!找零 ¥" + (paid - total));
        } else {
            System.out.println("余额不足,还差 ¥" + (total - paid));
        }

        String vip = paid >= 100 ? "金卡顾客" : "普通顾客";   // 三元
        System.out.println(vip);
    }
}
```

输出:

```text
余额不足,还差 ¥15.0
普通顾客
```

## 六、故意制造一个 Bug

把判断写成一个等号:

```java
if (paid = total) {   // ← 故意:= 而不是 ==
    System.out.println("出杯!");
}
```

---

## 七、读懂真实报错

```text
Cafe.java:6: error: incompatible types: double cannot be converted to boolean
        if (paid = total) {
                 ^
1 error
```

`paid = total` 是**赋值**,它的结果是一个 `double`,而 `if(...)` 需要 `boolean`。编译官拦下了。

> 小心:如果 `paid` 恰好是 `boolean` 类型,`if (flag = true)` **能编译通过**却永远为真 —— 那才是最阴险的版本。所以从一开始就养成 `==` 的肌肉记忆。

---

## 八、修复,并用测试证明

改回 `>=`。把「能否负担」抽成方法:

```java
static boolean canAfford(double paid, double total) {
    return paid >= total;
}
```

```java
@Test
void cannot_afford_when_short() {
    assertFalse(Cafe.canAfford(30.0, 45.0));
    assertTrue(Cafe.canAfford(50.0, 45.0));
}
```

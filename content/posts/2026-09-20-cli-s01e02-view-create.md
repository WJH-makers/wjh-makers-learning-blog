## 一、需求:看得见门,进不去书

上一话阿零学会了在服务器里走动。可刚站稳,豆豆就发来一条消息:「配置里端口写的多少?顺便看看昨天的访问日志有没有 404。」

阿零 `cd` 到了 `coffee-shop`,`ls` 也看见了 `config/app.conf`——然后卡住了。**文件就在眼前,他不知道怎么"打开"**:这个世界没有双击,没有记事本图标。想顺手建个 `backup` 目录当保险箱,也不知道从哪儿"新建文件夹"。

只能看名字、不能看内容的世界,和只读的橱窗没区别。今天要拿到两把新钥匙:**看**,和**造**。

## 三、本话目标

- "看"的四件套:`cat` 一口气倒、`less` 翻页(`q` 退出、`/` 搜索)、`head` / `tail` 只看两头;
- 记住 `tail -f`:站在文件末尾等新内容——以后盯线上日志全靠它;
- "造"的两件套:`mkdir`(`-p` 连父目录一起建)、`touch` 凭空一个空文件;
- 初见 `echo` 与 `>`:输出的去向可以从屏幕改成文件——**`>` 会覆盖**;
- 踩两跤:被困在 `less` 里出不来;把追加敲成覆盖,笔记一行不剩。

---

## 四、原理图:四种"看" + 两种"写"

```text
"看"的四件套:同一份文件,四种打开姿势
  cat  文件      → 全部倒出(小文件专用)
  less 文件      → 开窗翻页(大文件)  ← 全屏交互:空格翻页 b 回翻 /词 搜索 n 下一处 q 出门
  head -n 3 文件 → 只看头 3 行
  tail -n 5 文件 → 只看尾 5 行(-f:守在末尾等新内容,日志排障神器)

"造"与"写":
  mkdir 目录     (-p:父目录不存在就顺路一起建)
  touch 文件     (不存在则建 0 字节空文件;已存在只刷新时间戳,内容分毫不动)

  echo "文字"           → 打印到屏幕(屏幕 = 标准输出的默认去向)
  echo "文字" >  文件   → shell 先把文件截断清空,再写入   ⚠️ 覆盖,旧内容当场蒸发
  echo "文字" >> 文件   → 追加到末尾,旧内容安然无恙
```

一句话:**屏幕只是输出的默认去向;`>` 一出手,去向改了,旧内容也没了。**

## 五、上手:先看后造

看(在咖啡站目录和家目录):

```bash
$ cd ~/coffee-shop
$ cat config/app.conf              # 小文件:一口气倒出来
# coffee-shop 配置(暂行)
host=0.0.0.0
# TODO: move secret to env
port=8080

$ cd ~
$ head -n 3 logs/access.log        # 几百行的日志,先看个头
203.0.113.7 - - [19/Sep/2026:09:12:01 +0000] "GET / HTTP/1.1" 200 512
203.0.113.7 - - [19/Sep/2026:09:12:02 +0000] "GET /menu HTTP/1.1" 200 1893
198.51.100.23 - - [19/Sep/2026:09:13:47 +0000] "GET /favicon.ico HTTP/1.1" 404 209

$ tail -n 1 logs/access.log        # 再看个尾
203.0.113.7 - - [20/Sep/2026:09:00:02 +0000] "GET /coffee HTTP/1.1" 404 209

$ less logs/access.log             # 中间几百行:开窗慢慢翻,/404 搜索,n 下一处,q 退出
$ tail -f logs/access.log          # -f:守在末尾,新日志一来就滚出来(Ctrl+C 停)
```

造(家目录):

```bash
$ mkdir backup                     # 保险箱有了
$ mkdir backup/2026/09             # 想一次建两层……
mkdir: cannot create directory 'backup/2026/09': No such file or directory
$ mkdir -p backup/2026/09          # -p:缺哪层补哪层,一路铺到底

$ touch memo.txt                   # 凭空一个 0 字节文件
$ echo "先看清楚,再动手"            # echo:把字吐到屏幕
先看清楚,再动手
$ echo "先看清楚,再动手" > memo.txt # > 把去向从屏幕改成文件
$ cat memo.txt
先看清楚,再动手
```

> **特米旁白**:`cat` 全名 concatenate(拼接),把好几个文件首尾相连倒出来才是它的本职,以后用得上。今天先记口诀:**小文件 cat,大文件 less,只看两头 head / tail。**

## 六、故意制造一个 Bug:出不去,和回不来

晚上阿零想再翻一遍日志,进了 `less`,看完伸手就是 Ctrl+C——出不去;敲 `exit` 回车——屏幕纹丝不动。挣扎许久(最后是乱按碰到了 `q`)才逃出生天。

惊魂未定,他想把明天的待办**追加**进第 1 话就有的那份 `notes.md`,顺手敲:

```bash
$ echo "TODO: 凌晨两点备份日志" > notes.md
```

回车。无声无息,提示符照常回来——**看起来什么都没发生**。

## 七、读懂真实报错

**坑一**,被 `less` 关起来。屏幕底部只有这个:

```text
logs/access.log (END)
```

Ctrl+C、`exit`、Esc 全都没反应,顶多一声蜂鸣。根因:`less` 不是卡死,它是**全屏交互程序**——进去之后键盘归它管,Ctrl+C 被它接去干别的(中断搜索),不负责放人。修法就一个键:`q`。生存键一共四个:**空格翻页、`b` 回翻、`/词` 搜索(`n` 下一处)、`q` 出门**。这套手势是一整个家族的通用键位,第 5 话你会发现 `man` 的门也是它开的。

**坑二**,`>` 的无声覆盖:

```bash
$ cat notes.md
TODO: 凌晨两点备份日志
```

原来的三行笔记只剩这一行。**没有报错,才是最大的报错。**

根因:`>` 是 **shell** 的活,不是 echo 的——命令启动**之前**,shell 就把 `notes.md` 截断成 0 字节,再把 echo 的输出灌进去;echo 从头到尾不知道这个文件的存在。追加应该用 `>>`。

善后:这行字没有 Ctrl+Z、没有回收站,**找不回来了**(幸亏只是三行笔记,阿零凭记忆补回)。从今天起两条纪律:**追加一律 `>>`;敲 `>` 之前默念一遍目标文件名**。至于"动手前先复制一份保平安"——他现在还不会复制。明天的课,明天的坑。

> **🪟 双系统对照 · 看与造,PowerShell 上怎么打**

| 干什么 | Linux (bash) | PowerShell 7 | 关键差异 |
|---|---|---|---|
| 看整个文件 | `cat app.conf` | `Get-Content app.conf`(别名 `cat`/`gc`) | PS 返回**字符串数组对象**,一行一个元素;bash 吐的是文本流 |
| 分页看大文件 | `less access.log` | `Get-Content access.log \| more` | `less` 能回翻能搜索;`more` 只会往前走 |
| 只看头/尾 | `head -n 3` / `tail -n 5` | `Get-Content f -TotalCount 3` / `-Tail 5` | — |
| 守着文件尾 | `tail -f app.log` | `Get-Content app.log -Wait -Tail 10` | 都用 Ctrl+C 停 |
| 建目录带父级 | `mkdir -p a/b/c` | `mkdir a\b\c` | PS 的 mkdir **天生**会补父目录,不用旗子 |
| 空文件 | `touch memo.txt` | `New-Item memo.txt` | 小心:对已存在文件,touch 只摸时间戳,`New-Item -Force` 会**清空内容** |
| 覆盖 / 追加 | `>` / `>>` | `>` / `>>`(或 `Set-Content` / `Add-Content`) | **`>` 在两边都覆盖**——这个坑跨平台通用 |

> **🎯 面试直击**:`>` 和 `>>` 有什么区别?重定向是谁执行的?
> `>` 先把目标文件**截断**再写(覆盖),`>>` 打开后定位到末尾**追加**;重定向由 **shell** 在启动命令前完成,命令本身感知不到输出去了哪。追问:所以 `cat notes.md > notes.md` 会得到一个空文件——shell 先截断,cat 再去读时已经什么都不剩了。

## 八、用命令验证:看一眼,再看一眼

```bash
$ ls -F                            # 造出来的东西都在吗(/ 结尾的是目录)
backup/  coffee-shop/  logs/  memo.txt  notes.md

$ echo "教训:> 会覆盖,追加用 >>" >> memo.txt   # 这次用追加
$ cat memo.txt                     # 两行都在,旧内容没被吃
先看清楚,再动手
教训:> 会覆盖,追加用 >>

$ tail -n 1 memo.txt               # 刚学的 tail 立刻上岗:只验最后一行
教训:> 会覆盖,追加用 >>
```

写完就 `cat` 回读一眼——在没有弹窗确认的世界里,**回读就是你的确认框**。

# 《从零开始学 Java》06 · 批量制作:循环

> 第一季「点火篇」第 6 话 · 承接:能按编号报价的咖啡站。

---

## 一、需求:一次做 N 杯

排队 5 位顾客都点美式。总不能把「出杯」代码复制 5 遍。让程序**重复**做同一件事,直到做够为止。

---

## 二、漫画

> **〔1〕** 一条传送带循环转圈,每转一圈掉出一杯咖啡。
> 豆豆:「循环 = 重复执行,直到条件不再成立。」

> **〔2〕** 阿零写了个 `while`,却忘了每做一杯就减库存,传送带停不下来,咖啡堆成山。
> 豆豆:「循环体里**没有让条件靠近结束**,就是死循环。」

---

## 三、本话目标

- 用 `for` 做固定次数的重复;
- 用 `while` / `do-while` 做「直到某条件」的重复;
- 理解 `break`(跳出)/ `continue`(跳过本轮);
- 踩一次「忘记更新条件」的死循环。

---

## 四、原理图

```text
for (int i = 0; i < n; i++) { ... }   次数已知
while (条件) { ... }                   次数未知,先判断再执行
do { ... } while (条件);               至少执行一次
```

死循环根因:循环体没有让「条件」逐步趋向 `false`。

---

## 五、代码:做 5 杯 + 卖到库存为止

```java
public class Cafe {
    public static void main(String[] args) {
        // for:固定做 5 杯
        for (int i = 1; i <= 5; i++) {
            System.out.println("第 " + i + " 杯美式 ☕");
        }

        // while:一直卖,直到库存为 0
        int stock = 3;
        while (stock > 0) {
            System.out.println("售出一杯,剩余 " + (stock - 1));
            stock--;                 // ← 关键:让条件趋向结束
        }
    }
}
```

---

## 六、故意制造一个 Bug

把 `stock--` 删掉:

```java
while (stock > 0) {
    System.out.println("售出一杯,剩余 " + stock);
    // stock--;   ← 故意删掉
}
```

---

## 七、读懂现象(死循环)

终端疯狂刷屏「售出一杯,剩余 3」永不停止,得手动 `Ctrl+C` 才能停。`stock` 永远是 3,`stock > 0` 永远为 `true` —— 这就是**死循环**:忘了让条件靠近终点。

---

## 八、修复,并用测试证明

补回 `stock--`。把「按库存能卖多少杯」抽成方法:

```java
static int cupsSold(int stock) {
    int sold = 0;
    while (stock > 0) { sold++; stock--; }
    return sold;
}
```

```java
@Test
void sells_exactly_stock() {
    assertEquals(3, Cafe.cupsSold(3));
    assertEquals(0, Cafe.cupsSold(0));
}
```

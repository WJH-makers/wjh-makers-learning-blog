# 《从零开始学 Java》22 · Map 菜单索引

> 第二季「对象大陆」第 10 话 · 基线 JDK 25 · 承接:会员已能去重的咖啡站。

## 一、需求:按名字秒查咖啡

顾客说「拿铁」,咖啡站要立刻拿到它的价格和库存。用 `List` 得从头遍历,慢。需要「键 → 值」的直接映射 —— `Map`。

---

## 二、漫画

> **〔1〕** 一面墙全是带名牌的抽屉,报出名字就能直接拉开对应抽屉。
> 豆豆:「`Map` 就是键值对:给一个键,直接拿到值,不用挨个找。」

> **〔2〕** 豆豆掀开 HashMap 的底板:一排桶(数组),桶里挂着链表,链表太长就升级成红黑树。

---

## 三、本话目标

- 用 `Map<K,V>` / `HashMap` 存取键值对;
- 用 `getOrDefault` / `put` / `containsKey` / 遍历 `entrySet`;
- 了解 HashMap 底层:数组 + 链表 + 红黑树;
- 踩一次「对不存在的键取值得到 null 再调用 → NPE」。

---

## 四、原理图

```text
Map<String, Coffee> menu = new HashMap<>();
menu.put("拿铁", latte);      放
menu.get("拿铁");             取(键不存在返回 null)
menu.getOrDefault("摩卡", 缺省值);   取不到给默认
menu.containsKey("拿铁");     判断是否存在

底层:数组(桶) + 链表;同一桶元素过多(默认 8)且容量够 → 转红黑树,查询更快
```

## 五、代码:菜单索引

```java
import java.util.HashMap;
import java.util.Map;

record Coffee(String name, double price, int stock) {}

public class MenuIndex {
    public static void main(String[] args) {
        Map<String, Coffee> menu = new HashMap<>();
        menu.put("美式", new Coffee("美式", 15.0, 20));
        menu.put("拿铁", new Coffee("拿铁", 18.0, 10));

        Coffee c = menu.get("拿铁");
        System.out.println(c.name() + " ¥" + c.price());

        // 遍历所有键值对
        for (Map.Entry<String, Coffee> e : menu.entrySet()) {
            System.out.println(e.getKey() + " → 库存 " + e.getValue().stock());
        }
    }
}
```

## 六、故意制造一个 Bug

查一个菜单上没有的「摩卡」,直接用返回值:

```java
Coffee c = menu.get("摩卡");        // 键不存在,返回 null
System.out.println(c.price());      // ← 故意:对 null 调方法
```

---

## 七、读懂真实报错

```text
Exception in thread "main" java.lang.NullPointerException:
        Cannot invoke "Coffee.price()" because "c" is null
        at MenuIndex.main(MenuIndex.java:14)
```

现代 JDK 明确点名 `because "c" is null`。`get` 对不存在的键返回 `null`,直接 `.price()` 必崩。要么先 `containsKey` 判断,要么用 `getOrDefault` 给个兜底。

---

## 八、修复,并用测试证明

```java
static double priceOf(Map<String, Coffee> menu, String name) {
    Coffee c = menu.get(name);
    return c == null ? 0.0 : c.price();   // 缺货返回 0,不崩
}
```

```java
@Test
void price_lookup_is_null_safe() {
    var menu = Map.of("美式", new Coffee("美式", 15.0, 20));
    assertEquals(15.0, MenuIndex.priceOf(menu, "美式"));
    assertEquals(0.0, MenuIndex.priceOf(menu, "摩卡"));   // 不存在不崩
}
```

# 《从零开始学 Java》13 · Coffee 设计图:类与对象

> 第二季「对象大陆」第 1 话 · 基线 JDK 25 · 承接:第一季那台用平行数组拼出来的控制台咖啡机 v1。

---

## 一、需求:把「一杯咖啡」当成一个整体

第一季的菜单是三个平行数组:`MENU[]`、`PRICES[]`、还有想加的 `STOCK[]`。一旦排序或增删,名字、价格、库存就可能错位 —— 美式卖成了拿铁的价。

豆豆:「一杯咖啡的名字、价格、库存本来就该**绑在一起**。这就是对象。」

---

## 二、漫画

> **〔1〕** 豆豆铺开一张设计图,标题写着 `class Coffee`,下面列着字段:名字、价格、库存。
> 豆豆:「`class` 是**图纸**,`new` 出来的才是**实物**(对象)。」

> **〔2〕** 阿零按图纸造出两杯:一杯美式、一杯拿铁,各自带着自己的价格和库存,互不干扰。

---

## 三、本话目标

- 用 `class` 定义一类事物的字段(属性)和方法(行为);
- 用 `new` 创建对象、用 `.` 访问成员;
- 理解「图纸(类)」与「实物(对象)」的区别;
- 用构造器给对象初始化。

---

## 四、原理图

```text
class Coffee {          图纸:定义有哪些字段、哪些方法
    String name;
    double price;
    int stock;
}
Coffee c = new Coffee();   new:按图纸造一个实物,c 是指向它的引用
c.name = "美式";           . :访问对象的成员
```

---

## 五、代码:Coffee 类登场

```java
public class Coffee {
    String name;    // 字段:一杯咖啡有哪些数据
    double price;
    int stock;

    // 构造器:造对象时一次性初始化(方法名 = 类名,无返回类型)
    Coffee(String name, double price, int stock) {
        this.name = name;      // this.name 是字段,name 是参数
        this.price = price;
        this.stock = stock;
    }

    // 方法:一杯咖啡能做的事(行为)
    String describe() {
        return name + " ¥" + price + "(库存 " + stock + ")";
    }

    public static void main(String[] args) {
        Coffee americano = new Coffee("美式", 15.0, 20);
        Coffee latte = new Coffee("拿铁", 18.0, 10);
        System.out.println(americano.describe());
        System.out.println(latte.describe());
    }
}
```

输出:

```text
美式 ¥15.0(库存 20)
拿铁 ¥18.0(库存 10)
```

名字、价格、库存现在**天然绑在一起**,再也不会错位。

## 六、故意制造一个 Bug

把构造器里的 `this` 去掉:

```java
Coffee(String name, double price, int stock) {
    name = name;     // ← 故意:参数赋给自己,字段没被赋值
    price = price;
    stock = stock;
}
```

---

## 七、读懂现象(Logic Bug)

不报错,但 `describe()` 打印出 `null ¥0.0(库存 0)`。因为 `name = name` 是把**参数赋给参数自己**,同名的字段从没被碰过,保持默认值(对象字段默认 `null`/`0`)。必须用 `this.name = name` 区分「字段」和「参数」。

---

## 八、修复,并用测试证明

补回 `this.`。对象的方法照样能测:

```java
@Test
void coffee_describes_itself() {
    Coffee c = new Coffee("美式", 15.0, 20);
    assertEquals("美式 ¥15.0(库存 20)", c.describe());
}
```

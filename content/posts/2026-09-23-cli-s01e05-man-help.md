## 三、本话目标

- 装上求助四级火箭:`--help`(最快)→ `man`(最全)→ `man -k` / `apropos`(忘了命令叫啥)→ `tldr`(只要例子);
- 看懂 man 的**分节数字**:1 命令、5 文件格式、8 管理命令——`passwd(1)` 和 `passwd(5)` 同名不同物;
- man 页内导航 = less 同款:`/` 搜索、`n`/`N` 巡逻、空格翻页、`q` 出门;
- 学会读 **SYNOPSIS**:`[]` 可选、`...` 可重复、`|` 二选一、粗体照抄、斜体换成你的;
- 知道内建命令(`cd` 等)要用 `help`,man 里可能查无此人。

## 四、原理图:四级火箭与一本密码本

```text
求助四级火箭(从快到全):
  ① cmd --help       10 秒:参数速览,不进全屏(内建命令用 help cmd)
  ② man cmd          3 分钟:权威全文;翻页器就是 less,手艺全通用
  ③ man -k 关键词     忘了命令叫什么,按描述反查(= apropos)
  ④ tldr cmd         只想抄现成例子(社区维护,需安装)

man 的书架(分节号,同名条目靠它区分):
  1 用户命令      5 文件格式与约定      8 系统管理命令
  2 系统调用      3 C 库函数           (man 5 passwd = 指定去 5 号书架拿)

SYNOPSIS 密码本:
  rm [OPTION]... [FILE]...
      │        │
      │        └ ... = 可以重复多个
      └ [ ]    = 可以省略
  粗体/原样字符 → 照抄      斜体或 <尖括号> → 换成你的实际值      a|b → 二选一
```

一句话:**说明书不是用来背的,是用来查的——你要练的只有"查得快"。**

## 五、上手:四级火箭各点一次

一级,`--help` 快查(自答第 4 话的悬案):

```bash
$ tail --help
Usage: tail [OPTION]... [FILE]...
Print the last 10 lines of each FILE to standard output.
...
  -f, --follow[={name|descriptor}]
                             output appended data as the file grows
  -n, --lines=[+]NUM         output the last NUM lines, instead of the last 10
```

二级,`man` 精读;三级,`man -k` 反查:

```bash
$ man tail                     # 进 less:空格翻页,/follow 搜索,n 下一处,q 出门
$ man 5 passwd                 # 同名不同物:passwd(1) 是改密码的命令,passwd(5) 是 /etc/passwd 的格式
$ man -k copy                  # 只记得"复制",忘了命令叫啥 —— 按描述反查
cp (1)               - copy files and directories
scp (1)              - OpenSSH secure file copier
```

四级,`tldr` 抄例子;外加内建命令的暗门:

```bash
$ tldr tail                    # 例子优先(没有就 sudo apt install tldr)
  - Show last 'count' lines in file:
    tail --lines count path/to/file
$ man cd
No manual entry for cd
$ help cd                      # cd 是 bash 内建命令,说明书在 bash 自己手里
cd: cd [-L|[-P [-e]] [-@]] [dir]
    Change the shell working directory.
```

> **特米旁白**:`No manual entry for cd` 不是书丢了——`cd` 根本不是独立程序,是 bash 的内建功能,所以要问 bash 本人(`help`)。判断方法下一步会教:`type 命令名`。

## 七、读懂真实报错

**坑一**,搜索不是抽卡。`/` 只是把你送到**第一处**命中;巡逻靠 `n`。顺手贴上 less 家族的通用巡逻键表(man 也全适用):

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `/词` | 向下搜索 | `?词` | 向上搜索 |
| `n` | 下一处命中 | `N` | 上一处命中 |
| `g` / `G` | 跳到开头 / 结尾 | `q` | 退出 |

搜不到时它会明说,长这样(底部状态行):

```text
Pattern not found  (press RETURN)
```

**没看到这行,就说明有命中——接着按 `n` 巡逻,别急着宣判。**

**坑二**,方括号是语法,不是让你抄。真实回敬:

```text
rm: cannot remove '[OPTION]...': No such file or directory
rm: cannot remove '[FILE]...': No such file or directory
```

根因两层:① `[]` 和 `...` 是**语法记号**——"可省略"和"可重复",不是命令的一部分;② 顺带一记回旋镖:方括号在 shell 里本身还是通配符(`[OPTION]` 匹配 O/P/T/I/N 中的一个字符),无匹配才**原样传给了 rm**——上一话的知识点当场返场。特米的拆解:

- `rm [OPTION]... [FILE]...` 读作:「rm,后面**可以**跟若干个选项,再跟若干个文件」;
- 所以 `rm a.txt`(选项 0 个)与 `rm -I a.txt b.txt`(文件 2 个)都合法;
- 连 `rm` 单独敲都"符合语法"——只是它会用人话拒绝你:

```text
$ rm
rm: missing operand
Try 'rm --help' for more information.
```

> **🪟 双系统对照 · 求助系统,PowerShell 版**

| 干什么 | Linux (bash) | PowerShell 7 | 关键差异 |
|---|---|---|---|
| 看手册 | `man tail` | `Get-Help Get-Content -Full` | PS 帮助要先 `Update-Help` 联网下载;man 生来就在机器里 |
| 快查 | `tail --help` | `Get-Content -?` | — |
| 按关键词反查 | `man -k copy` / `apropos` | `Get-Command *copy*` 或 `Get-Command -Verb Copy` | bash 搜的是**文本描述**;PS 搜的是**命令对象**——动词-名词命名本身就是可发现性设计 |
| 只要例子 | `tldr tail` | `Get-Help Get-Content -Examples` | PS 例子内置在帮助里,不用装第三方 |
| 内建命令 | `help cd`(man 查无此人) | `Get-Help Set-Location` | PS 不分内建/外部,查法统一 |

老朋友再登场:`man -k` 在**纯文本**描述里做全文匹配;`Get-Command` 吐的是**对象**,还能按动词、名词、模块接着过滤——文本与对象,连"求助"都各按各的世界观来。

> **🎯 面试直击**:man 手册条目后面的数字(如 `passwd(1)`、`passwd(5)`)是什么意思?
> 是**分节号**:1 用户命令、2 系统调用、3 C 库函数、5 文件格式、8 系统管理命令。同名条目靠它区分——`man passwd` 打开改密码的命令,`man 5 passwd` 打开 `/etc/passwd` 的格式说明。追问:`man -k passwd` 能列出所有分节的相关条目;排障读配置文件时,记得先想想 5 号书架。

## 八、用命令验证:渔网自检


### 选择题(10 道)

1. `man` 命令的全称是什么?
   - A) manual(手册)　B) manage(管理)　C) manipulate(操作)　D) mandatory(强制)

2. 快速查看命令的常用选项摘要,用哪个命令最快?
   - A) `man command`　B) `command --help`　C) `info command`　D) `whatis command`

3. `man 5 crontab` 中的数字 `5` 代表什么?
   - A) 第 5 页　B) 第 5 节(文件格式与约定)　C) 版本号 5　D) 详细介绍级别

4. `type ls` 的输出为 `ls is aliased to 'ls --color=auto'`,这告诉我们什么?
   - A) `ls` 是一个外部程序　B) `ls` 被 alias(别名)覆盖了　C) `ls` 是一个 shell 内置命令　D) `ls` 没有被安装

5. `man -k keyword`(或 `apropos keyword`)的作用是?
   - A) 显示 keyword 命令的完整手册　B) 在所有手册的简短描述中搜索 keyword　C) 删除 keyword 相关的手册页　D) 查看 keyword 的第 k 节

6. SYNOPSIS 中 `ls [OPTION]... [FILE]...`的 `...` 表示什么?
   - A) 选项内容省略了　B) 前面标记的元素可以出现一次或多次　C) 该选项已废弃　D) 该参数是可选的

7. 以下 SYNOPSIS:`command [-a | -b] [-c] file`,正确解读是?
   - A) `-a`、`-b`、`-c` 必须同时使用　B) `-a` 和 `-b` 互斥(只能选一个),`-c` 可选,`file` 必需　C) `-a` 和 `-b` 都必须使用　D) 所有参数都是可选的

8. 你需要查看 `printf` 命令的 C 函数手册(第 3 节)而非 shell 命令手册(第 1 节),应该执行?
   - A) `man printf`　B) `man 1 printf`　C) `man 3 printf`　D) `info printf`

9. tldr 与传统 `man` 的核心区别是什么?
   - A) tldr 是 man 的替代品,内容完全一样　B) tldr 只提供常用示例,man 提供完整手册　C) tldr 是 GUI 工具,man 是命令行工具　D) tldr 必须联网,man 不需要

10. 执行 `type -a echo` 可能显示什么信息?

### 解答题(5 道)

**Q1 概念:** 列出"四级求助系统"——`--help`、`man`、`man -k`、`tldr`——各自的特点和适用场景。

**Q2 解释:** 解读这个 SYNOPSIS:`grep [OPTION]... PATTERNS [FILE]...`,并说明 `[...]`、`...` 和全大写 `PATTERNS` 在这种语法中的约定含义。

**Q3 操作:** 写出查找"查看磁盘使用"相关命令的完整流程:从不知道命令名到找到命令再到学会基本用法的全过程。

**Q4 排障:** 菜菜执行 `man printf`,看到的是 shell 内置命令的手册(第 1 节),但他想查 C 标准库函数 `printf(3)`。请分析为什么 `man printf` 默认打开第 1 节,并给出访问第 3 节的方法。

**Q5 综合设计:** 你面对一个完全陌生的命令 `journalctl`,请设计一套自学流程:先判断身份(`type`),再用四级求助依次递进(从快到全),最后总结出该命令的 3 个最常用场景及对应命令。

> [!答案]
> **1-A** `man` = manual,Unix 系统的在线参考手册。**举一反三:**`man man` 可以查看 man 自己的手册(非常"自指")。手册分 9 节:1=用户命令,5=文件格式,8=系统管理等。
>
> **2-B** `--help` 是最快的快查方式,直接输出命令的选项摘要。**举一反三:**四级求助速度排名:`--help` < `tldr` < `man` < `man -k`(快→慢);详细程度则相反。🪟 PowerShell 中 `Get-Help command` 等价于 `--help`,`Get-Help command -Full` 等价于 `man`。
>
> **3-B** `man` 手册第 5 节专门描述文件格式和约定,如 `man 5 crontab` 查看 crontab 文件的语法格式。**举一反三:**常见分节:1=用户命令,2=系统调用,3=C 库函数,5=配置文件格式,7=杂项,8=系统管理命令。用 `man -f keyword`(或 `whatis`)可以看某个关键词在哪些节中有条目。
>
> **4-B** `type` 显示命令的实际身份。输出为 alias 说明 `ls` 被别名覆盖了。**举一反三:**`type -a ls` 显示所有层级的定义;`which ls` 只找外部可执行文件,不显示别名和内置命令;`command -v ls` 是 POSIX 兼容的替代方案。
>
> **5-B** `man -k`(=`apropos`)搜索所有手册页的 NAME 和简短描述行。**举一反三:**想不起来"那个查进程的命令叫什么"时,用 `man -k process` 或 `man -k "list processes"` 搜索。`man -K`(大写 K)全文搜索,但很慢。
>
> **6-B** `...` 表示前一个元素可以重复一次或多次。`[OPTION]...` 表示可以给零个或多个选项。**举一反三:**SYNOPSIS 约定:`[...]`=可选,`...`=可重复,`|`=互斥(选 A 或 B),全大写=占位符(需替换为实际值)。学会读 SYNOPSIS 是最被低估的命令行能力。
>
> **7-B** `[-a | -b]` 方括号内用 `|` 分隔表示可选且互斥;`[-c]` 表示可选;`file` 无方括号表示必需。**举一反三:**严格来讲互斥的选项也可以都不选(因为整体在方括号内)。如果想表示"必选其中一项",应该写成 `(-a | -b)` 或用描述说明。
>
> **8-C** `man 3 printf` 明确指定第 3 节(C 库函数)。**举一反三:**`man -a printf` 可以按节号顺序浏览所有匹配的手册页,按 `q` 跳到下一个。
>
> **9-B** tldr(Too Long; Didn't Read)是社区维护的简化手册,只提供最常用的实际示例,忽略所有边缘选项。**举一反三:**四级求助的使用顺序:`command --help`(快速确认) → `tldr command`(看常用示例) → `man command`(深入了解) → `man -k topic`(探索未知命令)。🪟 tldr 也支持 PowerShell。
>
> **10-C** `type -a` 显示命令的所有定义来源,按优先级排序。**举一反三:**对于 `echo`,`type -a` 通常显示 `echo is a shell builtin` 和 `echo is /usr/bin/echo`,表明内置优先于外部程序。
>
> **Q1** 四级求助:①`--help`:秒级快查,直接看选项列表,适合"这个选项叫什么来着"。②`man`:完整手册,包含详细说明、所有选项、退出码、相关文件,适合"我要彻底搞懂这个命令"。③`man -k`(=apropos):按关键词搜索,适合"我想做 X 但不知道用哪个命令"。④`tldr`:社区维护的实用示例集,适合"给我几个拿来就能用的例子"。**使用策略:**--help→tldr→man→man -k,按需递进。
>
> **Q2** 解读:`grep [OPTION]... PATTERNS [FILE]...`。`grep`=命令名;`[OPTION]...`=零个或多个可选选项(方括号表可选,省略号表可重复);`PATTERNS`=必需参数,全大写表占位符(替换为实际模式);`[FILE]...`=零个或多个可选文件(不指定时默认读 stdin)。**举一反三:**所有 man 手册的 SYNOPSIS 都遵循这套约定,学会读语法图可以帮你理解任何新命令而不需死记硬背。
>
> **Q3** 查找流程:①`man -k "disk usage"` 或 `apropos "disk usage"` 搜索相关命令 ②搜索结果中看到 `du`(estimate file space usage) ③`du --help` 快速看选项 ④`tldr du` 看常用示例 ⑤`man du` 深入学习。**举一反三:**也可以用 `whatis du` 看一句话描述,`info du` 看 GNU Info 格式的详细文档(GNU 工具链的 info 通常比 man 更全面)。
>
> **Q4** `man` 默认按节号递增搜索,`printf` 在多个节都有条目(1=shell 命令,3=C 函数),所以 `man printf` 先找到第 1 节。**解决方法:**①`man 3 printf` 直接指定节号 ②`man -a printf` 浏览所有节(按 q 跳到下一个) ③`man -f printf`(whatis) 先看有哪些节的条目。**举一反三:**这也是为什么你要养成读手册时注意"页眉"的习惯——它会显示 `PRINTF(1)` 告诉你当前在看第 1 节。
>
> **Q5** 自学流程:①`type journalctl`确认是外部命令(位于 `/usr/bin/journalctl`),不是别名或内置。②`journalctl --help` 快速了解选项概览。③`tldr journalctl` 看实际常用示例(如查看启动日志、跟踪最新日志、按时间过滤)。④`man journalctl` 深入研究各选项。⑤总结三大场景:查看服务日志 `journalctl -u nginx`、实时跟踪 `journalctl -f`、按时间段过滤 `journalctl --since "2026-09-01" --until "2026-09-23"`。**举一反三:**面对任何新命令,遵循"判身份→快查→示例→深挖"四步法,这是终身自学的元能力。

## 三、本话目标

- 装上求助四级火箭:`--help`(最快)→ `man`(最全)→ `man -k` / `apropos`(忘了命令叫啥)→ `tldr`(只要例子);
- 看懂 man 的**分节数字**:1 命令、5 文件格式、8 管理命令——`passwd(1)` 和 `passwd(5)` 同名不同物;
- man 页内导航 = less 同款:`/` 搜索、`n`/`N` 巡逻、空格翻页、`q` 出门;
- 学会读 **SYNOPSIS**:`[]` 可选、`...` 可重复、`|` 二选一、粗体照抄、斜体换成你的;
- 知道内建命令(`cd` 等)要用 `help`,man 里可能查无此人。

## 四、原理图:四级火箭与一本密码本

```text
求助四级火箭(从快到全):
  ① cmd --help       10 秒:参数速览,不进全屏(内建命令用 help cmd)
  ② man cmd          3 分钟:权威全文;翻页器就是 less,手艺全通用
  ③ man -k 关键词     忘了命令叫什么,按描述反查(= apropos)
  ④ tldr cmd         只想抄现成例子(社区维护,需安装)

man 的书架(分节号,同名条目靠它区分):
  1 用户命令      5 文件格式与约定      8 系统管理命令
  2 系统调用      3 C 库函数           (man 5 passwd = 指定去 5 号书架拿)

SYNOPSIS 密码本:
  rm [OPTION]... [FILE]...
      │        │
      │        └ ... = 可以重复多个
      └ [ ]    = 可以省略
  粗体/原样字符 → 照抄      斜体或 <尖括号> → 换成你的实际值      a|b → 二选一
```

一句话:**说明书不是用来背的,是用来查的——你要练的只有"查得快"。**

## 五、上手:四级火箭各点一次

一级,`--help` 快查(自答第 4 话的悬案):

```bash
$ tail --help
Usage: tail [OPTION]... [FILE]...
Print the last 10 lines of each FILE to standard output.
...
  -f, --follow[={name|descriptor}]
                             output appended data as the file grows
  -n, --lines=[+]NUM         output the last NUM lines, instead of the last 10
```

二级,`man` 精读;三级,`man -k` 反查:

```bash
$ man tail                     # 进 less:空格翻页,/follow 搜索,n 下一处,q 出门
$ man 5 passwd                 # 同名不同物:passwd(1) 是改密码的命令,passwd(5) 是 /etc/passwd 的格式
$ man -k copy                  # 只记得"复制",忘了命令叫啥 —— 按描述反查
cp (1)               - copy files and directories
scp (1)              - OpenSSH secure file copier
```

四级,`tldr` 抄例子;外加内建命令的暗门:

```bash
$ tldr tail                    # 例子优先(没有就 sudo apt install tldr)
  - Show last 'count' lines in file:
    tail --lines count path/to/file
$ man cd
No manual entry for cd
$ help cd                      # cd 是 bash 内建命令,说明书在 bash 自己手里
cd: cd [-L|[-P [-e]] [-@]] [dir]
    Change the shell working directory.
```

> **特米旁白**:`No manual entry for cd` 不是书丢了——`cd` 根本不是独立程序,是 bash 的内建功能,所以要问 bash 本人(`help`)。判断方法下一步会教:`type 命令名`。

## 六、故意制造一个 Bug:抽卡式搜索,和照抄方括号

坑一:阿零在 `man rm` 里想找大写 `-I` 的解释,敲 `/interactive`,命中的第一处是 `--interactive[=WHEN]` 前面的一段普通描述,不是他要的条目。他当场宣布「手册里没有!」,`q` 退出,重进,又从头搜了一遍。

坑二:他盯着 SYNOPSIS 里的 `rm [OPTION]... [FILE]...`,把 `...` 理解成"后面省略没写完",于是**原样**敲进了终端:

```bash
$ rm [OPTION]... [FILE]...
```

## 七、读懂真实报错

**坑一**,搜索不是抽卡。`/` 只是把你送到**第一处**命中;巡逻靠 `n`。顺手贴上 less 家族的通用巡逻键表(man 也全适用):

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `/词` | 向下搜索 | `?词` | 向上搜索 |
| `n` | 下一处命中 | `N` | 上一处命中 |
| `g` / `G` | 跳到开头 / 结尾 | `q` | 退出 |

搜不到时它会明说,长这样(底部状态行):

```text
Pattern not found  (press RETURN)
```

**没看到这行,就说明有命中——接着按 `n` 巡逻,别急着宣判。**

**坑二**,方括号是语法,不是让你抄。真实回敬:

```text
rm: cannot remove '[OPTION]...': No such file or directory
rm: cannot remove '[FILE]...': No such file or directory
```

根因两层:① `[]` 和 `...` 是**语法记号**——"可省略"和"可重复",不是命令的一部分;② 顺带一记回旋镖:方括号在 shell 里本身还是通配符(`[OPTION]` 匹配 O/P/T/I/N 中的一个字符),无匹配才**原样传给了 rm**——上一话的知识点当场返场。特米的拆解:

- `rm [OPTION]... [FILE]...` 读作:「rm,后面**可以**跟若干个选项,再跟若干个文件」;
- 所以 `rm a.txt`(选项 0 个)与 `rm -I a.txt b.txt`(文件 2 个)都合法;
- 连 `rm` 单独敲都"符合语法"——只是它会用人话拒绝你:

```text
$ rm
rm: missing operand
Try 'rm --help' for more information.
```

> **🪟 双系统对照 · 求助系统,PowerShell 版**

| 干什么 | Linux (bash) | PowerShell 7 | 关键差异 |
|---|---|---|---|
| 看手册 | `man tail` | `Get-Help Get-Content -Full` | PS 帮助要先 `Update-Help` 联网下载;man 生来就在机器里 |
| 快查 | `tail --help` | `Get-Content -?` | — |
| 按关键词反查 | `man -k copy` / `apropos` | `Get-Command *copy*` 或 `Get-Command -Verb Copy` | bash 搜的是**文本描述**;PS 搜的是**命令对象**——动词-名词命名本身就是可发现性设计 |
| 只要例子 | `tldr tail` | `Get-Help Get-Content -Examples` | PS 例子内置在帮助里,不用装第三方 |
| 内建命令 | `help cd`(man 查无此人) | `Get-Help Set-Location` | PS 不分内建/外部,查法统一 |

老朋友再登场:`man -k` 在**纯文本**描述里做全文匹配;`Get-Command` 吐的是**对象**,还能按动词、名词、模块接着过滤——文本与对象,连"求助"都各按各的世界观来。

> **🎯 面试直击**:man 手册条目后面的数字(如 `passwd(1)`、`passwd(5)`)是什么意思?
> 是**分节号**:1 用户命令、2 系统调用、3 C 库函数、5 文件格式、8 系统管理命令。同名条目靠它区分——`man passwd` 打开改密码的命令,`man 5 passwd` 打开 `/etc/passwd` 的格式说明。追问:`man -k passwd` 能列出所有分节的相关条目;排障读配置文件时,记得先想想 5 号书架。

## 八、用命令验证:渔网自检

```bash
$ whatis rm                    # whatis = 只取 man 首页那一行简介
rm (1)               - remove files or directories

$ man -k passwd                # 反查:确认同名条目真的分住不同书架
passwd (1)           - change user password
passwd (5)           - the password file

$ type cd                      # 验证 cd 真是内建 —— 所以 man 里没有它
cd is a shell builtin
$ type rm
rm is /usr/bin/rm
```

渔网自检通过:**从今天起,遇到陌生参数,先问机器,再问搜索引擎。**

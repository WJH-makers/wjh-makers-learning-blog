# 为什么我要开始写学习日志

> 这是本站的开篇，也是使用说明。如果你只想找入口，直接跳到第三节。

## 一、建站目的

我希望这个博客不是“展示用的空壳”，而是每天都能使用的学习系统。

每篇文章尽量回答四个问题：

- 今天解决了什么问题？
- 我用了哪些命令、工具或资料？
- 中间踩了哪些坑？
- 下次遇到类似问题如何更快解决？

写作格式固定成一条链，先追求稳定记录，再追求表达质量：

```text
目标 -> 过程 -> 命令 -> 结果 -> 复盘
```

## 二、八个阶段的学习路线

这条路线是按“**下一步能不能立刻动手**”排的，不是按知识体系的完整度排的。每个阶段都有一个可验证的出站标准——达不到就别往下走，跳过去只会在后面某处塌方。

| 阶段 | 学什么 | 出站标准（能做到才算过） | 本站入口 |
|---|---|---|---|
| 1 · 能跑起来 | 装环境、写第一个程序、认识报错 | 在一台干净机器上从零装好并跑通 Hello World，看得懂编译报错 | [《从零开始学 Java》](/java) S1 |
| 2 · 语法与 OOP | 变量、流程、集合、类与接口、泛型、异常 | 能独立写出一个几百行的控制台程序，出错知道从哪查 | [/java](/java) S1–S2 |
| 3 · 命令行与 Git | 文件操作、管道、进程、权限、Git 分支与回退 | 不靠图形界面完成一次改代码 → 提交 → 回滚 | [《从零开始玩命令行》](/cli) |
| 4 · 构建与依赖 | Maven/Gradle、模块化、测试 | 能解释一次依赖冲突是怎么来的，并写出会失败的单元测试 | [/java](/java) S3 · [速查](/posts/2026-07-26-maven-gradle-cheatsheet) |
| 5 · 数据库 | 表设计、事务、索引、执行计划 | 给一条慢查询看 `EXPLAIN`，说清索引为什么这样建 | [/java](/java) S10 · [速查](/posts/2026-07-21-mysql-redis-cheatsheet) |
| 6 · Web 后端 | HTTP、Spring Boot、鉴权、接口设计 | 从一个请求讲到数据落库，包括失败时回滚到哪 | [/java](/java) S4 |
| 7 · JVM 与并发 | 内存模型、GC、锁、字节码、排障工具 | 拿到一次线上卡顿，能用 `jstack` / `jcmd` 自己定位 | [《JVM 火种纪》](/jvm) |
| 8 · 上线与运维 | 打包、容器、部署、日志、监控 | 把自己的项目部署到一台真实服务器并能查它的日志 | [/cli](/cli) S5 · [速查](/posts/2026-07-26-docker-compose-cheatsheet) |

**进阶卷**（阶段 8 之后按需选，不必顺读）：分布式、云原生、性能、架构、安全、消息、可观测、大数据、搜索、源码精读——见 [/series](/series) 的全部连载索引。

> 一条实话：真正卡住大多数人的不是阶段 7 那些难的，而是阶段 1 到 3 反复没走稳——环境装不好、命令行不敢用、Git 一冲突就重新 clone。这三样磨熟了，后面反而顺。

## 五、五个最常见的劝退坑

这几条不是道理，是我自己或身边人真栽过的：

1. **环境装了三天还没跑起来，就开始怀疑自己不适合编程。** 环境问题跟智商无关，它只是一堆版本和路径的琐事。设个上限：两小时搞不定就换方案（用容器、用别人的镜像、换 JDK 发行版），别在这里消耗掉热情。
2. **教程看得很爽，一动手就空白。** 看视频是在看别人解决问题，不是自己解决。硬性规定：每看完一节，关掉视频，凭记忆重写一遍，卡住的地方才是你真正没学会的地方。
3. **收藏了四十份资料，一份没看完。** 同时开三条以上的学习线，等于零条。任何时候只留一条主线 + 一条工具线。
4. **只学不留证据。** 学完不留代码、不留可复现的记录，三个月后等于没学。这也是 [/career](/career) 那条线开篇要解决的问题：让做过的东西能被别人验证。
5. **卡住了就重新开始。** 从头再学一遍基础，是最舒服也最没用的逃避方式。卡住的正确做法是把问题缩小到能提出来的程度——能清楚描述出来的问题，通常已经离解决很近了。

## 一、需求:关了机也记得住

每天打烊一关程序,菜单、库存全部清零,第二天开门又得从头录入。豆豆:「内存是**临时**的,断电即忘。想让数据活过关机,得把它写进**文件**——那才是能落地的记忆。」

## 三、本话目标

- 用 `Path` 表示文件位置,`Files` 读写文件;
- 认识第一个 **checked 异常** `IOException`——编译官强制你处理;
- 用 **try-with-resources** 自动关闭资源,告别手动 `finally` 关流;
- 踩一次"相对路径找不到文件"的坑并看懂 `NoSuchFileException`;
- 用测试验证"存进去再读出来,数据一致"。

---

## 四、原理图:Path 是地址,Files 是搬运工

```text
Path.of("menu.csv")     一张写着位置的纸条(未必真有文件)
        │
        ▼   交给搬运工 Files
Files.writeString(path, text)   写
Files.readString(path)          读(小文件)
Files.readAllLines(path)        读成 List<String>(按行)
Files.newBufferedReader(path)   开一个可逐行读的流(大文件,配 try-with-resources)
```

两个关键提醒:

- **相对路径**(`menu.csv`)是相对**进程的工作目录**——从哪儿敲 `java` 命令,就从哪儿找;换个目录运行就找不到。要稳,用绝对路径或显式指定目录。
- **字符编码**:Java 18 起(JEP 400)默认字符集统一为 **UTF-8**,中文菜单跨平台不再乱码——这是近年最省心的默认值之一。

## 五、代码:把菜单存进文件、再读回来

```java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.LinkedHashMap;
import java.util.Map;

public class MenuStore {
    private static final Path FILE = Path.of("menu.csv");

    // IOException 是 checked 异常:方法要么 throws、要么 try —— 编译官盯着
    static void save(Map<String, Integer> stock) throws IOException {
        StringBuilder sb = new StringBuilder();
        stock.forEach((name, qty) -> sb.append(name).append(',').append(qty).append('\n'));
        Files.writeString(FILE, sb.toString());   // 默认 UTF-8
    }

    static Map<String, Integer> load() throws IOException {
        Map<String, Integer> stock = new LinkedHashMap<>();
        if (Files.notExists(FILE)) return stock;       // 没文件就返回空,别硬读
        for (String line : Files.readAllLines(FILE)) {
            if (line.isBlank()) continue;
            String[] p = line.split(",");
            stock.put(p[0], Integer.parseInt(p[1]));
        }
        return stock;
    }
}
```

调用处必须处理这个 checked 异常:

```java
public static void main(String[] args) {
    Map<String, Integer> menu = new LinkedHashMap<>();
    menu.put("美式", 20);
    menu.put("拿铁", 15);
    try {
        MenuStore.save(menu);                     // 写盘
        Map<String, Integer> loaded = MenuStore.load();  // 关机后再读回
        System.out.println("读回菜单:" + loaded);
    } catch (IOException e) {
        System.out.println("菜单读写失败:" + e.getMessage());
    }
}
```

## 六、故意制造一个 Bug:相对路径陷阱

在项目根目录能跑,换到 `src/` 子目录再 `java` 运行同一份程序去读:


## 七、读懂真实报错:NoSuchFileException

```text
Exception ... java.nio.file.NoSuchFileException: menu.csv
	at java.base/...
	at MenuStore.load(MenuStore.java:19)
```

`NoSuchFileException` 后面直接跟着**它去找的那个路径**。八成不是文件没了,而是**你以为的"当前目录"和程序真正的工作目录不是同一个**。排查一句话:先 `System.out.println(FILE.toAbsolutePath())` 打出它到底在找哪儿,真相立刻浮现。

> **豆豆锐评 · 为什么流一定要关**
> 文件流、网络连接这类资源占着操作系统的句柄,不关就**泄漏**——句柄耗尽会让程序再也打不开新文件。手写 `finally { reader.close(); }` 容易漏、还可能在 close 时又抛异常盖住原始错误。**try-with-resources** 帮你在括号里的资源用完后**逆序自动关闭**,前提是它实现了 `AutoCloseable`(几乎所有流都实现了)。

> **⏳ 版本时光机 · 文件读写怎么一步步变简单的**

| JDK 版本 | 写法 | 变化 |
|---|---|---|
| Java 6 | `FileReader` + `BufferedReader`,手动 `finally { close() }` | 啰嗦、易漏关 |
| Java 7 | `try (var r = new BufferedReader(...)) { }` 自动关 | try-with-resources 登场 |
| Java 11 | `Files.readString` / `writeString` 一行读写小文件 | 小文件党福音 |
| Java 18 | 默认字符集转 **UTF-8**(JEP 400) | 中文跨平台不再乱码 |

> **🔀 豆豆的多解台 · 读文件,选哪个 API?**

| 方式 | 代码要点 | 适合 |
|---|---|---|
| `Files.readString(path)` | 一次读成一个 `String` | 小文件、要整块内容 |
| `Files.readAllLines(path)` | 按行读进 `List<String>` | 小文件、按行处理(本话用它) |
| `Files.newBufferedReader` + try-with-resources | 逐行读、省内存 | 大文件 |
| `Files.lines(path)` | 返回**流**,惰性逐行 | 大文件 + 流式处理(是 Stream,**下一话专讲**) |

豆豆锐评:菜单这种小文件,`readAllLines` 最省事;等文件大到几百 MB,再换 `newBufferedReader` 或 `Files.lines` 逐行,别一次性全读进内存。

## 八、修复后用测试证明:存进去 = 读出来

```java
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.io.TempDir;
import java.nio.file.Path;
import java.util.*;
import static org.junit.jupiter.api.Assertions.*;

class MenuStoreTest {
    @Test
    void save_then_load_roundtrip(@TempDir Path dir) throws Exception {
        // @TempDir 给一个临时目录,测试完自动清理,不污染真实文件
        Path file = dir.resolve("menu.csv");
        java.nio.file.Files.writeString(file, "美式,20\n拿铁,15\n");
        List<String> lines = java.nio.file.Files.readAllLines(file);
        assertEquals(2, lines.size());
        assertEquals("美式,20", lines.get(0));
    }
}
```

JUnit 的 `@TempDir` 专为文件测试而生:给你一个用完即焚的临时目录,**测试不碰你的真实文件、也不会互相干扰**。
